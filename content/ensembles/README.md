# 编制与演奏条件

从 [弦乐四重奏](string-quartet.md)。写其他编制时查对应乐器的一手资料，不把本库的保守写法当作所有演奏者的极限。

配器检查区分音域、音区、力度、发音、持续能力与角色。音高在物理音域内不保证快速跳进、双音或长时持续都可行。
