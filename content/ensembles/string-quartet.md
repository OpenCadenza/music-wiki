# 弦乐四重奏 String quartet

编制：两把小提琴、中提琴、大提琴。四个谱表应有稳定身份；中提琴默认中音谱号，大提琴通常低音谱号，必要时换谱号。弦乐均按实音核查。

## 从谱到写作

常规空弦（从低至高）小提琴 G3–D4–A4–E5，中提琴 C3–G3–D4–A4，大提琴 C2–G2–D3–A3。这里只列调弦，不给统一最高音或“舒适音域”。调弦及奏法核对 [Philharmonia 乐器资料](https://philharmonia.co.uk/resources/instruments/) 的 Violin / Viola / Cello 页面与演示；该网站素材只作链接，不复制。

先为每段分配主题、对位、脉冲、低音或融合和声的角色。角色可以交换；让出重音、音区与持续时间，才能使新主导线条可辨。四声部无需永远等量活动。

连弓与分弓影响乐句、重音和呼吸。pizzicato 改变延续性；arco 返回应明确。双音和和弦需结合弦位、手型与速度复核，MIDI 播出不证明可演奏。高把位、泛音、特殊弓法需要具体演奏资料或演奏者确认。

## 适用边界与证据

以上角色审查是本项目的写作工作法，不是外部教材的硬性规范。以 [OpenScore 四重奏编码](https://github.com/OpenScore/StringQuartets) 及 [拉威尔案例](../composers/ravel/index.md) 对照具体织体。弦乐音色的融合、弓压和真实平衡无法由符号检查充分判断；保留试听和演奏审稿项。
