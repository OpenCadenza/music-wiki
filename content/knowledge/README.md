# 来源与知识索引

知识入口见 [任务索引](../README.md)；来源登记为 [sources.json](sources.json)。知识正文只有一份，按用途链接，不按标签复制。通过稳定 ID 或 facets 搜索到专题后，连同范围、反例与来源位置一起读取。

## 证据与许可

- `established` 表示限定范围内的教材规则；`provisional` 表示待进一步验证；`interpretive` 表示有谱面证据的分析解释。计算报告另行标记，不使用不存在的 computed 枚举。
- 当前源码与匹配编译产物支持技术事实；来源和谱面支持音乐分析。编译器不能裁决曲式或艺术质量，标签不能覆盖实际音符。
- 教学模型、真实摘录和分析简化分别注明。摘录记录作品、乐章、小节、声部、编码者、原版本及源哈希；省略、转写和改编明确列出。
- 项目审稿、哈希、入库约定使用 project-workflow 来源，属于本地流程，不伪装成记谱标准或外部乐理定律。
- 具体许可见 [LICENSE](../LICENSE.md)。第三方谱例逐项保留许可和署名；公开阅读不自动等于可分发或可训练。

## 知识卡字段

现有卡片保持 `## id:` 稳定键，以及 type、facets、sources、confidence、scope、signals、counterexample、limits 字段。新专题采用知识 ID、直接来源定位、分析与边界；不为凑卡数拆分内容。卡片数量和篇幅没有固定上限。

格式卡见 [记谱](../notation/README.md)，曲式卡见 [曲式](../forms/README.md)，发展与对位见 [技法](../techniques/README.md)，风格与配器见 [风格](../styles/README.md)。实际作品案例归属对应作曲家，见 [作曲家索引](../composers/README.md)。
