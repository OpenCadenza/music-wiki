# 旋律大九度怎样把一句话带进新的音区？

把上行全音的落点升高一个八度，得到上行大九度（14 个半音）。相邻的两个音级仍然容易辨认，
但两音之间的音区距离可以让落点突然凸显。第六交响曲终乐章排练号 107 后，大管让这个落点
一闪而过，把时值留给它解决到的音。

## 第六交响曲终乐章：G₂ → A₃ → G₃

从总谱第 157 页第二小节起，第一大管与第二圆号先奏实音 G₂–D₃–G₂。末尾的 G₂ 是带断奏的
八分音符。下一小节第一拍，两件乐器从 G₂ 上跳到 A₃，短暂休止后再落到同一高音区的 G₃。
以下截取第一大管，从跳进前一小节起算。

```lilypond title="马勒 第六交响曲 终乐章" location="Etwas fliessender，排练号 107 后，总谱第 157 页第 2–6 小节" id="mahler-6-iv-ninth"
\version "2.26.0"
\language "english"

\score {
  \new Staff {
    \set Staff.instrumentName = "Fagott 1"
    \set Staff.midiInstrument = "bassoon"
    % GM 70
    \clef bass
    \key ef \major
    \time 4/4
    \tempo "Etwas fliessender" 4 = 66

    g,2\pp d4. g,8-. |
    a8 r8 g2 g,8 r8 |
    d8\< r8 g8[ r16 bf16] g'2->\! |
    d'1->\>~ |
    d'4\pp r4 r2 |
  }
  \layout { }
  \midi { }
}
```

A₃ 是前面 G–D–G 骨架外的音。它占强拍，只有八分音符的长度。落到的 G₃ 占半小节，随后
大管退回 G₂，再从 D₃ 起步，经过 G₃、B♭₃ 抬到带重音的 G₄。这个 G₄ 才获得半音符的停留。
同一个 G 在三个八度里分别承担出发、解决和攀升后的落点。听这几小节时，可以先追踪三个 G，
再听高处的 A 如何把其中前两个接起来。

## 写给 Agent 的任务

1. 写一个两小节旋律，第一小节在主音与五度音之间活动，末尾回到低处的主音。下一小节在强拍
   从这个主音向上跳大九度，安排一个短时值，再级进回到高处的主音。
2. 做一个试听对照，只把九度落点和随后解决的音都下移八度。两版保留相同音级、时值与起音位置，
   听高音区的转折是否来自这一个八度的变化。
3. 检查输出的实音。以 G₂ 为起点，A₃ 应相差 14 个半音，之后的 G₃ 应回落 2 个半音。
   如果移调、自动选八度或音域限制改变了这两处距离，重新试听转折。
