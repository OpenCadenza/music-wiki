# 巴赫

本目录把巴赫的写法拆成可观察、可迁移的音乐机制，避免把“巴赫风格”简化成连续十六分音符或固定和弦公式。任务涉及复调时，先读对拍和赋格的基础说明，再按作品机制选择以下案例。

| 类型专题 | 对照与机制 | 适用任务 |
| --- | --- | --- |
| [键盘复调](examples/keyboard-counterpoint.md) | BWV 772 / 846：动机交接、声部进入、成对作品职责 | 二声部对话、赋格、跨段织体 |
| [键盘变奏](examples/keyboard-variations.md) | Aria / Var.1：和声框架与表层动作 | 变奏、保留与改变 |

## 使用边界

- 先识别实际声部数、调性、终止和固定材料，再使用“巴赫式”标签。
- 把可计数的音程、进入、时值和和声事件与解释分开。赋格没有单一固定曲式；不是每个伴随声部都是 countersubject。
- 迁移示例中的节奏或轮廓时改变具体旋律、终止位置和织体细节，不能把短例当成完整作品模板。
- 示例中的 LilyPond 源保留采集时的语法版本。运行版必须由 `references-origin/` 自动迁移并由目标 LilyPond 编译，不能手工改写 `references/`。
