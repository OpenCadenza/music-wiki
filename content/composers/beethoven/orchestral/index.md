# 交响与协奏

选交响曲或协奏曲；区分全曲导读与局部织体模型。

进一步讨论分为[交响曲](symphonies/index.md)、[协奏曲](concertos/index.md)。这些分支限定各自的编制与段落语境，相关机制通过正文交叉引用。

<!-- aliases: Beethoven, 贝多芬, orchestral music, 管弦乐, symphony, 交响曲, concerto, 协奏曲, orchestration, 配器, solo, tutti -->

本目录处理贝多芬交响曲与协奏曲中的大型合奏问题。先按体裁进入；每个体裁 README 再按“想解决什么写作问题”指向叶子文档。


配器、乐章连接和调性目标可横向比较，作品归属仍以具体作品为准。“英雄”“命运”“皇帝”等称呼只有在其接受史与来源范围内使用。

读取叶子页时，把问题、来源定位、机制、完整谱例、逐音解释、迁移方法与边界一起读。一个九部作品导读链接不能独自支持逐小节和配器判断。
