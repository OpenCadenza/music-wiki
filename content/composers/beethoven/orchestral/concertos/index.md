# 协奏曲

Piano Concerto 1–5、Op.61、Op.56；solo / tutti、责任交接。

<!-- aliases: concerto, 协奏曲, Piano Concerto, 钢琴协奏曲, Violin Concerto, 小提琴协奏曲, Triple Concerto, 三重协奏曲, Op.15, Op.19, Op.37, Op.56, Op.58, Op.61, Op.73, solo, tutti -->

协奏曲的写作难点不只是“独奏旋律加乐队和弦”，而是让双方在同一段落中交换材料、确认调性、推动过渡、延迟解决并保留背景能量。先在下表定位作品和材料深度，再到[独奏与乐队责任转移](solo-tutti-responsibility.md)读取跨作品机制和完整原创谱例。

| 作品或问题 | 当前材料能支持什么 | 边界与缺口 |
| Op.19 与 Op.15 的作品先后 | LA Phil 记述 Op.19 降B大调先由乐队陈述主题，钢琴先围绕副主题、再展开主主题；终曲由钢琴提出材料。BSO 将 C 大调 Op.15 的形成定于约 1795–98、独奏者以新材料进入，而没有奏出乐队的军乐主题。两者支持“作品编号不是创作先后”。[LA Phil](https://www.laphil.com/works/piano-concerto-no-2-beethoven)；[BSO](https://www.bso.org/works/beethoven-piano-concerto-no-1) | 两篇都是乐团导听，不代替总谱；不同来源的年代说法需并列。 |
| Op.37 第一乐章 | Anna Scalfaro 的全文分析把它说明为古典协奏曲双重呈示：乐队先呈主要主题，钢琴以另一种分工再陈述；奏鸣曲式与回旋式 tutti 回归并存。[Scalfaro, pp.211–237](https://cris.unibo.it/handle/11585/590769) | 只集中第一乐章；曲式命名和分期是作者分析，不可写成所有学界共识。 |
| Op.58 第二乐章 | Young Eun Kim 的[论文记录](https://repository.lsu.edu/gradschool_dissertations/1348/)显示其目录和摘要结合形式、和声、历史演奏与阐释；本轮未取得全文。 | 摘要不能承担具体和弦、节拍或段落事实。先补全文和总谱；“奥耳甫斯”故事不能当作作曲家已证程序。 |
| Op.73 第一乐章 | BSO、Berliner Philharmoniker 与 Beethoven-Haus 手稿目录提供完整导听入口：钢琴回应弦乐和弦，第二主题有大小调变体，乐章有非传统华彩终曲；首主题含八分音符加三连十六分音符核心。[BSO](https://www.bso.org/works/piano-concerto-no-5-emperor)；[Berliner Philharmoniker](https://www.berliner-philharmoniker.de/en/programme-notes/ludwig-van-beethoven-concerto-for-piano-and-orchestra-in-e-flat-major-op-73/)；[Beethoven-Haus](https://www.beethoven.de/en/media/view/5653332433567744/Ludwig%2Bvan%2BBeethoven%2C%2BSkizzenblatt%2Bzum%2BKlavierkonzert%2BNr.%2B5%2Bop.%2B73%2C%2B1.%2BSatz%2C%2BAutograph?fromWork=5723434050912256) | 现有三源足够做聆听和织体导航，不足以代替逐小节总谱分析。“皇帝”是后世称呼，不是贝多芬确认的标题。 |
| Op.61 第一乐章 | Robin Stowell 的章节摘要把作品描述为交响性的大尺度组织：独奏与乐队共享并发展主题，小提琴有时评述或装饰既有陈述，木管与小提琴音色组合关键；Popović 提供带小节号的形式—戏剧分析。[Stowell](https://www.cambridge.org/core/books/beethoven-violin-concerto/structure-and-style-i-1-allegro-ma-non-troppo/4E0813A56F26C3792868CC4723999FA4)；[Popović](https://www.gmth.de/zeitschrift/artikel/898.aspx) | 两份来源集中在第一乐章；后两乐章、华彩和演奏历史另补材料。 |
| Op.56 | Rakochi 的同行评审文章指出首乐章乐队呈示较短，三个独奏者进入后独奏呈示和展开显著扩张，乐队更常标记段落、作引子或归纳；文章把作品置于独奏协奏曲、大协奏曲传统与室内三重奏交界。[Rakochi, pp.77–112](https://dspace.ut.ee/bitstreams/5d57eb2b-c3fb-4b99-bb29-d642b13f37b5/download) | 这是作者的分析框架，不是唯一体裁标签；研究还可扩展到更多乐章和声部细节。 |

该目录没有完成 Op.58 全文、Op.73 同行评审全曲分析、Op.61 后两乐章、Op.56 全曲形式图。新增正文时先从这些具体缺口补总谱和来源，再从作品事实中归纳方法。
