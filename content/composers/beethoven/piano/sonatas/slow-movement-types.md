# 慢乐章不止一种"慢"：咏叹型、变奏型、进行曲型

慢乐章的速度数字只说明每秒几拍，不说明它在套曲里干什么活。同样是四分音符 40 到 72，Op.31 No.2 的第二乐章在"停"，Op.90 的第二乐章在"唱"，Op.27 No.2 的开头在"不停"。三种慢法各有一套维持注意力的手段：一个把时间切开，一个把时间唱满，一个把时间抹平。位置也因此不同——切开的一般放在第二乐章，唱满的往往要兼任末乐章，抹平的可以直接当第一乐章。

## 一、咏叹型：Op.31 No.2 第二乐章用什么维持张力

```lilypond title="贝多芬 Op.31 No.2 第二乐章" location="Adagio，mm.1–9"
\version "2.26.0"
\language "english"

\score {
  \new PianoStaff <<
    \new Staff = "up" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef bass \key bf \major \time 3/4 \tempo 4 = 40
      <d f bf>2.\p\arpeggio^\markup { \large "Adagio." }
      \clef treble d''8..( ef''32) f''4 \clef bass <d f bf>4 <ef f a>2. \clef treble a''8..( bf''32) c'''4 <c' ef'>4
      <bf d'>2. \bar "" \cadenzaOn \override NoteHead.font-size = #-2 d'16([ f' ef' d' ef' f' g' a' bf' c''])
      \cadenzaOff \bar "|" \override NoteHead.font-size = #0 d''8..( ef''32) f''4 <af' f''>4\sf
      << { f''4( ef''8)[ d'' c''\staccato( c''\staccato)] c''8^\trill[ \grace { b'16[ c''] } d''16 c''] c''8 } \\ { g'4.\p bf'!8_\markup { \italic "cresc." }[ bf' bf'] bf'4( a'!8) } >> r8
      \clef bass r16 f16\p([ <ef! g> <c a>]) << { bf2. } \\ { <bf, d>8.( <c ef>32 <d f>4) <d f>4 } >> \clef treble d''8(~ d''16.^\turn ef''32) f''4 \clef bass <d f bf>4
    }
    \new Staff = "down" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef bass \key bf \major \time 3/4
      <bf,, f, bf,>2.\p\arpeggio r4 r <bf,, f, bf,>4 <c, f, c>2. r4 r <a, f>4 <bf, f>2. s2 s8
      r4 r <d b>4
      << { b4( c'8)[ d' ef' e'] e'4( f'8) d'8\rest } \\ { ef4. f8[ g\staccato( g\staccato)] f4. d8\rest } >> r4 bf,,2.
    }
  >>
  \layout { ragged-right = ##f }
  \midi { }
}
```

第 1 小节两行都只给主和弦。右手在低音谱表上写 d–f–b♭，带琶音记号，力度 p；左手是同一个和弦低两个八度（b♭–f–b♭）。整小节没有旋律，也没有第二个和声。

第 2 小节才出现乐思，而且它不是一条线，是一个手势：`d''8..( ef''32) f''4`，附点八分加三十二分写出一个"顶上去"的倚音式进行，第 3 拍回到 `<d f bf>`。第 3 小节 `<ef f a>2.` 配左手的 `<c, f, c>`，合起来是 f–a–c–e♭，属七；第 4 小节同型移位到 `a''8..( bf''32) c'''4`，左手 `<a, f>`；第 5 小节 `<bf d'>2.` 回主。五小节，五个和弦，一小节一个。

张力就是从这里来的：和声节奏是一小节一拍，低音一直是和弦音，没有一次经过性的走动。听者被钉在同一个和声平面上，变化只能发生在装饰和音色上。咏叹型的慢，本质是"把时间切成方块，然后一块一块给你"。

第一刀在第 5 小节的末尾。`<bf d'>2.` 之后紧接一句十个十六分音符的宣叙（d′–f′–e′–d′–e′–f′–g′–a′–b♭′–c″），写在 `\cadenzaOn` 里，不设小节线，所以这一小节比前面的都长；第 6 小节从 `d''8..( ef''32) f''4` 起，收在 `<af' f''>4\sf`——整段第一个强制重音，落在这一小节的第 3 拍。前面五小节的 p 与一小节一个和弦，都是为了把这个 sf 养出来。

第 7 小节继续用内声部做文章：右手 `f''4( ef''8)[ d'' c'' c'']` 之后接颤音，左手给 `g'4. bf'8[ bf' bf']`——后半小节三个重复音。重复音在这里不是伴奏音型，是把和声钉住的手段：上方在动，下方不动。第 8 小节 `r16 f16([ <ef! g> <c a>])` 只有一拍，随后左手把 b♭ 拉长成三拍。

写这种段落可以照抄的参数是三样：一小节一个和弦；低音用长音占满整小节；装饰型写成实值而不是小音符。三者一起，时间就被切成方块了。

## 二、歌唱型：Op.90 第二乐章为什么标"要唱得出来"而不是"慢"

Op.90 第二乐章的速度标记是 Nicht zu geschwind und sehr singbar vorgetragen——不要太快，要非常歌唱地奏出。它给的是两条指令：一条否定速度，一条规定发音方式。四分音符 72 不是慢速，2/4 拍一小节约 1.7 秒，接近说一句话的长度。

```lilypond title="贝多芬 Op.90 第二乐章" location="Nicht zu geschwind und sehr singbar，mm.17–24"
\version "2.26.0"
\language "english"

\score {
  \new PianoStaff <<
    \new Staff = "up" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef treble \key e \major \time 2/4 \tempo 4 = 72
      <as' as''>4( <e'' e'''> |
      <ds'' ds'''>4.) <a'! a''!>8( |
      <gs' gs''>4 <d'' d'''> |
      <cs'' cs'''>4.) \crescTextCresc <cs'' cs'''>8\<( |
      <bs' bs''>[ <cs'' cs'''>]) <a' a''>\staccato([ <gs' gs''>\staccato]) |
      <gs' gs''>8( <fs' fs''>4) <fs' fs''>8\! |
      <fs' fs''>8\p([ <b' b''> <as' as''> <b' b''>]) |
      <e' e''>4 r4 |
    }
    \new Staff = "down" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef bass \key e \major \time 2/4
      cs16 as fs cs fs, as fs cs |
      b, b fs ds b, b cs a! |
      b, gs e b, e, gs e b, |
      a, a e cs a, e a, e |
      gs, e a, e <a, cs> e <b,! e> gs |
      <cs e> as <cs e> as <c e> a <c e> a |
      <b, ds>16 a <b, ds> a <b, ds> a <b, ds> a |
      <e gs> e ds cs b, a, gs, fs, |
    }
  >>
  \layout { ragged-right = ##f }
  \midi { }
}
```

这一段把"唱"的机制摊开了。旋律全部用八度叠置：`<as' as''>`、`<e'' e'''>`、`<ds'' ds'''>`——上面一条线，下面一条同音的影子，像一个人唱、一件乐器跟着。句子最短两小节（第 17–18、19–20、21–22、23–24），每句的落点是 `4.` 或 `4`，句尾从不切碎。

左手是连续十六分音符的分解和弦，一小节八次，节奏型一次也不换：cs–as–fs–cs–fs,–as–fs–cs 这样的音型从第 17 小节一直滚到第 24 小节。它提供的是匀速，不是节拍重音——八分音符一直在走，听者感觉不到"拍"，只感觉到"呼吸在继续"。

所以"sehr singbar"是一条速度说明：速度由声乐的呼吸定，不由情绪的浓度定。这句话反过来也成立——如果一个慢乐章写的是长句、八度叠置、左手匀速十六分音符，它标"歌唱地"比标"慢"准确；标 adagio 反而会让人把句子拉断。

和咏叹型的差别就在"断"与"不断"。Op.31 No.2 第 5 小节末用宣叙把时间切开，Op.90 第 17–24 小节一次也没有停：左手十六分音符从不歇，句子靠落点换气，不靠休止换气。

## 三、伴奏型：Op.27 No.2 第一乐章的三连音做了什么

Op.27 No.2 第一乐章 Adagio sostenuto 的第一小节，右手是 g♯–c♯–e 的三连音，一小节四组，共十二个八分音符；左手是 `<cs cs,>` 的全音符八度。第 2 小节右手不变，左手换 `<b b,>`；第 3 小节 `<a a,>2 <fs fs,>`；第 4 小节 `<gs gs,> <gs gs,>`；第 5 小节 `<cs gs cs,>`。右手在三连音之上另有一条线，第 2 小节才进来，而且只是同一个音：`gs'8. gs16`，pp。

三连音在这里办了三件事。

第一，它把强拍藏起来。三连音的第一个音确实落在拍点上，但一小节四组三连音意味着每拍换一组，新旧组之间没有力度差，重音被摊平成流体。听者数不出小节，只能感到和声在走。

第二，它让和声变化成为唯一的时间标记。左手用全音符，一小节才换一次和弦；右手十二个音全都属于同一个和弦。于是"走到下一个和弦"就是这一段里唯一的事件，而这个事件一小节只发生一次。

第三，它把"慢"变成"不停"。速度可以很慢，但运动密度高——一小节十二个音，手指从不离开键盘。耳朵不觉得静止，只觉得慢。

这三种机制不能互相替代。咏叹型靠停，歌唱型靠唱满，伴奏型靠不让手停下来。混着用会得到一段既不庄严也不流动的东西。

## 四、变奏型与进行曲型

另两种慢法走的是完全不同的路。

变奏型（Op.57 第二乐章）不改速度，改的是主题被拆解的参数：音值、拍位、织体。它的慢是"同一句话说了很多遍"，靠每次变形的距离维持注意力。判断哪一变还在说同一句话、哪一变已经换了性格，见[《慢乐章的变奏：什么时候是装饰，什么时候是换性格》](slow-movement-variation.md)。

进行曲型（Op.26 第二乐章，Marcia funebre sulla morte d'un Eroe）反过来：附点节奏、低音八度像鼓点、旋律大量使用重复音。它慢是为了"走"，不是为了"唱"或"停"。写这类段落时，速度要给足行走的空间，重音要落在脚步上，句子长度按队列而不是按呼吸来分。

四种慢法的区别可以一句话记住：咏叹型让时间停住，歌唱型让时间流成句子，伴奏型让时间流成液体，进行曲型让时间走成队列。

## 五、各放哪个位置

位置由功能决定，不由速度决定。

咏叹型适合第二乐章。第一乐章刚把张力花完，听者需要一次明确的"停"，而咏叹型的方块和声、长音低音、宣叙打断正好提供这个停。Op.31 No.2 就是这么用的。

歌唱型适合末乐章，或者像 Op.90 那样只有两个乐章时兼任末乐章。它必须同时是"慢"和"收"，所以不能真的慢下去——左手十六分音符提供匀速，旋律提供呼吸。两乐章方案里这个位置怎么分配重量，见[《只有两个乐章时，结构重量往哪里挪》](op90-two-movements.md)。

伴奏型适合第一乐章。Op.27 No.2 用三连音让整首曲子从一片没有重音的流体开始，后面的快板才有东西可撞。

进行曲型适合第二乐章或第三乐章。它给的是"行走"，通常用来把一个庄重的场合撑满，或者在大结构里做一次外部世界的插入。

## 三条可以带走的规则

一，先决定这个慢乐章要不要"停"。要停，就写方块和声、长音低音、宣叙式打断，且把唯一的强重音留在一个整小节的空隙之后（Op.31 No.2 第 5 小节末）。不停，就写匀速的内声部，让句子靠落点换气而不是靠休止换气（Op.90 第 17–24 小节）。

二，装饰型必须是实值。`8..` 加 `32` 和"小音符"是两件事：实值能被数出来，能被重复，能承担乐思；小音符只是装饰。Op.31 No.2 第 2 小节的整个乐思就是那个 `8..+32`。

三，慢乐章的音符密度和目标速度反着走。速度越慢，越需要一层不歇的内声部（三连音、十六分音符、重复音）把时间填满；速度稍快而标着"歌唱地"，反而要减少装饰，让句子自己站住。
