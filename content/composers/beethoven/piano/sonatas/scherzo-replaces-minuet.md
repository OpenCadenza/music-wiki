# 谐谑曲取代小步舞曲：换了什么，没换什么

小步舞曲和弦谑曲都是三拍子，都在奏鸣曲的第三乐章，都带一个 Trio 然后 da capo。看起来只是换了个名字，实际换的是重音落在哪里。小步舞曲把最后半拍做成向上的弱起，把重量推到下一小节第 1 拍，因为身体的舞步需要一个"抬起来"的动作；谐谑曲反过来，把重音直接砸在第三拍上，让舞步踩不下去。结构和调性框架几乎原样保留，换掉的是速度与重音位置这两个参数。

## 一、小步舞曲的骨架：两小节一个舞步周期

这一段逐音的谱面见[《终章用什么曲式》](finale-choice.md)里的 Op.49 No.2 第二乐章谱例（mm.1–12）。

Op.49 No.2 的第二乐章是标准的小步舞曲。一拍弱起 `g'8.( fs'16)`——附点八分加十六分，向上够到下一小节的 `fs'`。

骨架有三层。

第一层是三拍。全曲没有一个变拍号，每小节三拍，一小节就是一个完整的手臂起落。

第二层是两小节一个舞步周期。第 1 小节 `fs'2 fs'8.( g'16)`：前两拍是一个二分音符的 fs′，第三拍拆成附点八分加十六分，向上够；第 2 小节 `g'2 g'8.( b'16)` 是同一个句式换了一个音。第 1–2 小节合成一步，第 3–4 小节合成第二步，第 5–6 小节回头重复第 1–2 小节。舞蹈上这叫一组 pas de menuet，六拍一步。

第三层是弱起的方向。第 1 小节末尾的 `fs'8.( g'16)` 把 `g'16` 放在小节最后一拍的最后一个十六分上，紧接着下一小节第 1 拍就是 `g'2`。这条链一直贯到第 8 小节：`g'4 r4 b'8. b'16` 的最后那个 `b'16` 又是向上够。

还有第四层，在左手。第 1 小节的低音是 `<a c'>8 d' d d' <a c'> d'`——六个八分音符，两个双音分别落在第 1 拍与第 3 拍上。一个三拍子里，低音只标出第 1 拍与第 3 拍，中间的 2 拍滑过去。这就是小步舞曲的两拍感：手臂每小节提两次，旋律把第 3 拍做成向上够。

四层加起来的效果是：每一小节的第 1 拍都被上一小节"推"出来，而第 3 拍永远处在准备状态。舞者踩的是第 1 拍，抬的是第 3 拍。这就是为什么小步舞曲不能快——一旦快到一个舞步压进两秒，抬腿的时间就没了。

## 二、第一次把第三乐章标成 Scherzo 的是 Op.2 No.2

先厘清一件事。Op.2 三首奏鸣曲的第三乐章标记并不一样：No.1 是 Menuetto. Allegretto，No.2 是 Scherzo. Allegretto，No.3 是 Scherzo. Allegro。第一次把第三乐章标成 Scherzo 的是 Op.2 No.2，A 大调，Trio 在 a 小调。

但音乐上的转折发生得更早。Op.2 No.1 第三乐章虽然印着 Menuetto，写的已经不是小步舞曲了。


弱起是一拍 `<c' af'>4`，断奏，p。它不是向上够，是砸下来。第 1 小节的左手更说明问题：`r4 r f4`——低音在第 3 拍才进来，第 1、2 拍完全空着。这和 Op.49 No.2 第 1 小节左手第 1 拍就落 `<a c'>8` 正好相反。

四小节一句话，第 5–8 小节原样换个音区再说一次。第 4 小节的第 3 拍是一个断奏和弦 `<ef'! c''>4`；第 12 小节 `af'4 r g''8\sf( f'')` 的重音落在第 3 拍的第一个八分上。

差别就在这里。小步舞曲的第 3 拍是准备，谐谑曲的第 3 拍是打击。Op.2 No.1 把"抬起来"的那个拍位换成了"砸下去"的拍位，身体的反应从"起跳"变成"被绊一下"。这才是谐谑曲的本意——不是更快，是重心错位。

速度上，两段谱例分别用的是四分音符 120 与 168。同样三拍子、同样两小节一组，120 还能走舞步，168 已经不能：一小节 1.07 秒，一组舞步两小节 2.1 秒，腿来不及抬到第二个位置。

## 三、Trio 保留了小步舞曲的结构功能

```lilypond title="贝多芬 Op.2 No.1 第三乐章" location="Trio，mm.1–8"
\version "2.26.0"
\language "english"

\score {
  \new PianoStaff <<
    \new Staff = "up" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef treble \key f \major \time 3/4 \tempo 4 = 168 \partial 4 c'4\p^\markup { "Trio." }
      a'8([ g' a' f' g' a'] bf'[ a' bf' g' a' bf'])
      c''([ b' c'' d'' c'' bf'] a'[ g' a' bf' a' f'])
      << { a'4( c'' f'') } \\ { a'2. } >>
      << { g'( d'' f'') } \\ { g'2. } >>
      << { f''4\rest f''4( e'') } \\ { g'2. } >>
      << { e''4\rest d''4( c''!) } \\ { f'2 e'4 } >>
    }
    \new Staff = "down" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef bass \key f \major \time 3/4 \partial 4 r4
      f4( a c'
      d' g f
      e g c'
      f a c')
      a,8([ gs, a, f, g, a]
      bf,[ a, bf, g, a, b,]
      c[ b, c a, b, cs]
      d[ a, b, g, c! fs,])
    }
  >>
  \layout { ragged-right = ##f }
  \midi { }
}
```

Trio 是小步舞曲留下的、谐谑曲一个也没改的部分。

调性：Menuetto 在 f 小调，Trio 换到 F 大调——同名大调，主音不动，只换三度。这是小步舞曲 Trio 最典型的做法，用最省力的方式换色彩。

织体：Menuetto 是和弦块（第 1 小节 `<df' bf'>4( <bf g'>) r4`，三拍里两拍是双音），Trio 换成单线八分音符跑动：`a'8([ g' a' f' g' a'])`，六连音一组，一小节一组。左手前半是四分音符琶音（`f4( a c'`），第 5 小节起换成十六分音符的音阶型（`a,8([ gs, a, f, g, a]`）。

长度：Trio 比 Menuetto 短。这里八小节就结束了一整句。

再现：Trio 结束在 `c'4 r4`，之后整个 Menuetto 原样 da capo。三段体 A–B–A 一个不少。

da capo 这一下值得单独说。谐谑曲如果只把 A 段重复一遍，听者会觉得没写完；Trio 的作用是先把调性、织体、音区全部换掉（f 小调→F 大调、和弦块→单线跑动、中音区→中高音区），再把 A 段原样放回来。放回来的时候，前面的 Menuetto 已经听过两遍（两个反复），第三遍靠"刚从一个完全不同的地方回来"这件事实撑住。这是小步舞曲时代留下的最要紧的一条结构公式：三段体的第三段不需要新内容，需要的是一个刚离开过的距离。

Op.2 No.1 的 Trio 还多做了一件事：它把八分音符跑动压进了低音（第 5 小节起 `a,8([ gs, a, f, g, a]`），而主段里全是和弦块。等到 da capo 回来，第 1 小节那个 `<df' bf'>4( <bf g'>) r4` 的空旷感会比第一次更明显——因为耳朵刚被八分音符塞满。

所以"没换"的清单很清楚：三拍子、Trio 的调性对比（同名大小调）、三段体与 da capo。谐谑曲把 Tempo di Menuetto 换成 Allegretto 或 Allegro，把第 3 拍的重音方向反过来，把句子的长度弄得不整齐，但这三样结构骨架一直留着。

## 四、换了什么，没换什么

换了三样。

速度。小步舞曲的舞步周期是两小节六拍，这个物理时间决定上限。谐谑曲不受这个约束，可以去到 168 甚至更快。

重音位置。小步舞曲把第 3 拍做成向上的弱起，重量推给下一小节第 1 拍；谐谑曲把重音放在第 3 拍本身（Op.2 No.1 第 12 小节的 sf），或者干脆让第 3 拍空着、由另一只手补进来（第 1 小节左手 `r4 r f4`）。

句法。小步舞曲严格两小节一步，四小节一句，八小节一段；谐谑曲的句子可以只有两拍（Op.2 No.1 第 1 小节就是一个两拍手势加一个休止），也可以突然拉长。

没换的是三样：三拍子；三部性结构（A–B–A + Trio）；Trio 的调性对比功能。

## 五、写谐谑曲时可以照做的四条

一，先决定第 3 拍是"抬"还是"砸"。抬，就写弱起（附点八分加十六分、向上级进），把最后一拍的最后一个十六分交给下一个强拍的邻音；砸，就把重音记号、断奏、sf 放在第 3 拍的第一个音上，且让另一只手在第 1、2 拍空着。

二，把第 1 拍让出去一次。Op.2 No.1 第 1 小节左手第 1、2 拍全休止，只弹第 3 拍；这个"低音迟到"比任何重音记号都更快地把舞曲感打掉。

三，Trio 换同名调，不换主音。f 小调到 F 大调只差一个音（a♭ 变 a♮），写起来省力，听觉上却是一次明确的换色。

四，Trio 的织体要和主段相反。主段是和弦块，Trio 就写单线八分音符；主段是八分音符跑动，Trio 就回到和弦。同一种织体在两段里连着出现，三段体就听不出分界。

一句话：谐谑曲不是"更快的小步舞曲"，是把小步舞曲的重心从第 1 拍挪到第 3 拍的同一个三拍子框架。名字换了，骨架没换；速度换了，调性布局没换。
