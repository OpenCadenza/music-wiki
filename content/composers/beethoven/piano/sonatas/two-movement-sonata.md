# 把奏鸣曲压到最短：Op.78 的两个乐章靠什么站住

Op.78 是三十二首钢琴奏鸣曲里最短的一首，只有两个乐章，两个乐章都是升 F 大调。它没有慢乐章——慢的只有开头四小节，实际发声的只有三小节加一拍；它也没有谐谑曲。四乐章方案里由"慢"和"舞"两段承担的卸力功能，在这里全部落空。这篇要回答的就是：这种压缩之后，结构靠什么还站得住。

```lilypond title="贝多芬 Op.78 第一乐章" location="Adagio cantabile，mm.1–8"
\version "2.26.0"
\language "english"

\score {
  \new PianoStaff <<
    \new Staff = "up" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef treble
      \key fs \major
      \time 2/4
      \tempo "Adagio cantabile" 4 = 40
      % m.1：两音起手，立刻加厚成三音
      <as cs'>4\p( <as cs' fs'>8. <b es' gs'>16)
      % m.2
      <b es' gs'>4( <cs' fs' as'>8) <cs' e' as'>
      % m.3：旋律升到 b′，内声部跟着换
      << { b'4( ds''8. cs''16) }
         \\ { <ds' fs'>4 <es' gs'> }
      >>
      % m.4：只有一拍，延长记号收住引子
      \partial 4
      << { b'32([ as' ds'' cs'']) cs''8^\fermata }
         \\ { s4 }
      >>
      % m.5：Allegro 的弱起，也只有一拍
      \time 4/4
      \partial 4
      \tempo "Allegro ma non troppo" 4 = 132
      as'8.( b'16)
      % m.6：主题用四音和弦进入
      <b cs' es' b'>2.\f <gs cs' gs'>4(
      % m.7
      <as cs' as'> <ds' ds''> <cs' cs''> <fs' fs''>
      % m.8
      <es' es''>) <ds' ds''> <cs' cs''> as'16 b' as' fs'
    }
    \new Staff = "down" {
      \set Staff.midiInstrument = "acoustic grand"
      % GM 0
      \clef bass
      \key fs \major
      \time 2/4
      % 引子的低音是四小节不动的踏板音
      <fs,, fs,>2\p
      <fs,, fs,>2
      <fs,, fs,>2
      \partial 4
      <fs,, fs,>4^\fermata
      \time 4/4
      \partial 4
      r4
      % m.6：八分音符分解，f♯ 出现五次
      fs,8 fs as fs b fs as fs
      % m.7
      gs8 cs gs cs gs cs es cs
      % m.8
      fs,8 fs b, fs as, fs ds fs
    }
  >>
  \layout { }
  \midi { }
}
```

## 一、两个乐章各自是什么

第一乐章分两段。开头四小节是 Adagio cantabile，2/4 拍，四分音符 40。第 1 小节右手先给两音 a♯–c♯′，第二拍加厚成三音 a♯–c♯′–f♯′，这一拍的最后一个十六分换成 b–e♯′–g♯′；第 2 小节从 b–e♯′–g♯′ 起，中间插一个 c♯′–f♯′–a♯′，收在 c♯′–e′–a♯′；第 3 小节旋律升到 b′，内声部是 d♯′–f♯′ 与 e♯′–g♯′ 两条两音和弦；第 4 小节只剩一拍，四个三十二分音符带出 c♯″，停在延长记号上。整个引子左手只有一个音：f♯₁–f♯₂ 的八度，四小节一动没动。

第 5 小节是 Allegro ma non troppo 的弱起，4/4 拍，四分音符 132，长度只有一拍，内容是 a♯′ 附点八分接 b′ 十六分——两个音，一个二度。第 6 小节主题才正式进来，一上来是四音和弦 b–c♯′–e♯′–b′，左手同时铺开八个八分音符，其中五个是 f♯，夹进两个 a♯ 与一个 b。

第二乐章是 Allegro vivace，2/4 拍，四分音符 128，调性仍是升 F 大调。它的主题由两音和弦串成，反复出现的两对是 f♯′–b′（纯四度）与 f♯′–a♯′（大三度）；力度在 f 与 p 之间反复直跳，和弦带断奏。整章没有一条长旋律，全部由这种"两音一拍"的碎片拼起来。

## 二、引子只出现一次，而且必须只出现一次

引子在整章里只出现一次。往后翻：没有第二个 2/4 段落，没有第二个延长记号，没有第二个四分音符 40 的速度；第一乐章最后一小节只剩下一个断奏的 f♯ 大三和弦，其余三拍空着。

这件事在四乐章方案里是不可想象的。Op.13 第一乐章的 Grave 在展开部里回来一次，在结尾之前还要再回来——慢引子在那里是一个"可以回收的地址"，它把开头的重量记在账上，后面再结算。Op.78 把这一笔账直接划掉了。

划掉之后，收束的责任全部转移给 Allegro。第一乐章不能靠"引子回来"来收尾，只能靠主题本身把话说尽：所以它的两个半部各自带了反复记号，前半（呈示部）反复一次，后半（展开与再现）再反复一次。反复记号在这里不是习惯，而是**唯一还能拉长结构时间的手段**——没有慢乐章可以让人喘气，就把两个半部各奏两遍，让听者在重复里获得停顿。

代价也很清楚：听者没有转身的地方。引子结束在第 4 小节的延长记号上，一个延长记号之后紧接着就是 132 的 Allegro，中间没有任何过渡。这种接法在四乐章里做不到，因为后面还有三个乐章要接；在两乐章里它反而成了优势——第一乐章一开口就把两种速度都摆出来了。

## 三、两个乐章共享什么

**调性不换。** 两个乐章都是升 F 大调，六个升号，从头到尾没有换过主音。这在两乐章奏鸣曲里是罕见的：Op.90 第一乐章 e 小调、第二乐章 E 大调，靠同名大小调直换；Op.111 第一乐章 c 小调、第二乐章 C 大调，同样是同名转换。Op.78 不做这个转换，于是"对比"必须从别处来。

**从拍号的密度来。** 第一乐章的 Allegro 是 4/4、四分音符 132，一小节 1.82 秒，每分钟约 33 个小节；第二乐章是 2/4、四分音符 128，一小节 0.94 秒，每分钟约 64 个小节。速度数字只差 4，但强拍出现的频率差了近一倍。听感上第二乐章"更快"，不是因为它的四分音符更快，而是因为每一拍都成了强拍位。

**从音数来。** 引子第 1 小节从两音（a♯–c♯′）起手，一拍之后才加到三音；第二乐章的主题每一拍只有两个音。两个乐章都把"最薄的音数"当成开头：先给骨架，再决定要不要加厚。第一乐章加了，第二乐章一直不加。

**从附点来。** 引子用附点八分加十六分（一小节里两次），Allegro 的弱起也是附点八分加十六分，第二乐章的主题是附点四分加八分。三处都靠附点取得"推进感"，落点却不同：引子把附点放在拍内，弱起把附点放在拍尾，第二乐章把附点放在拍头。

**从收束来。** 两个乐章的最后一小节都是断奏的 f♯ 和弦，都不给长音。第一乐章收在 f♯–a♯–c♯″–f♯‴，第二乐章收在 f♯′–c♯′–f♯–c♯ 的空五度音型上。同一个主音、同一种触键，把两个乐章缝在一起。

## 四、和 Op.90、Op.111 比：这是"省"还是"另一种完整"

Op.90 的两个乐章是"对置"：e 小调对 E 大调，3/4 对 2/4，156 对 72，第一乐章把张力花完，第二乐章换同名大调结账。它的两乐章靠调性对立成立，长度上两个乐章都不短。

Op.111 的两个乐章是"失衡"：第一乐章以 Maestoso 开场，转快板后一路暴烈推进，篇幅压得很紧；第二乐章 Arietta 加变奏，长度压倒第一乐章。它靠规模对立成立——第二乐章大到可以吞掉第一乐章。

Op.78 两样都不是。它的两个乐章调性相同、规模相近、拍号起点相同，对比全压在速度、拍号密度与触键上。所以它不是"省下两个乐章"，而是**把对比从调性层搬到了织体层**：同一调性内，用 4/4 的和弦块与 2/4 的两音碎片对打。这是另一种完整，不是残缺的四乐章。

代价是听者拿不到"调性换了"这种最省力的对比信号。收益是没有任何一段是过场：第一乐章没有一段可以抽出来单演，第二乐章也没有一段是纯粹的过渡。

## 五、被合并掉的四个环节

**慢乐章压成三小节加一拍。** 慢的功能只剩"开场一次"，它不再是一个乐章，而是一个姿态。四乐章里慢乐章要负责卸力、要负责抒情、要负责和第一乐章形成音区与音色的对照；这里它只负责把 f♯ 这个低音钉在听者耳朵里，然后立刻让开。

**谐谑曲整个消失。** 舞曲段的功能是打碎句法、换一种步态；Op.78 把它换成了第二乐章的两音和弦——步态确实换了，但不再是一个独立乐章。

**引子的再现被删掉。** 这一条前面说过：慢引子不回来，于是"引子的回收"这个环节整个不存在。

**再现部的准备被弱起吸收。** 第一乐章的主题每次进来都靠同一对音：a♯′ 附点八分接 b′ 十六分。这两个音既是引子的尾巴（第 5 小节），也是主题的发射台（第 6 小节），还是在再现部之前把主题领回来的铰链。有了这个弱起，就不需要另写一段过渡：准备段被压缩成两个音，附在主题前面。

## 六、可迁移的写法

要写两乐章，按下面几条落地。

第一，先决定对比放在哪一层。若两个乐章同调，就必须在拍号、音数、触键三项里至少换两项；Op.78 换了三项（4/4 换 2/4、四音和弦换两音和弦、连奏换断奏），只留调性不动。

第二，把慢的功能压缩到一个可计算的单位。Op.78 给的是四小节、一个持续低音、一个延长记号；这三样加起来就够让耳朵记住主音的重量。不要试图在四小节里塞进一个完整的慢乐章主题。

第三，短引子要么不回来，要么就必须短到不需要回来。写了四小节引子又让它回来，等于用两次四小节换一次十二小节的功能，不划算；不回来，就必须让主调在引子里被彻底钉住——Op.78 用的是四小节不动的 f♯ 八度。

第四，把结构的伸长度交给反复记号，而不是新增段落。两个半部各反复一次，等于把篇幅翻倍而不增加材料；在两乐章方案里，这是唯一不花钱的"呼吸"。

第五，让两个乐章共用同一个终止手势。同调两乐章最怕结尾听起来像同一首曲子的两个版本；解决办法是让收束在触键上一致、在音数上不同——Op.78 两个乐章都以断奏的 f♯ 和弦收尾，都不再给长音：第一乐章停在 f♯–a♯–c♯″–f♯‴，第二乐章停在 f♯″–a♯″–f♯‴。
