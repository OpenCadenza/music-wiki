# 德彪西：层、平面与音色

德彪西的钢琴与管弦乐作品常被缩成“印象派”或“模糊和声”。更有用的分析单位是具体织体：哪些音共同移动，哪些线保持独立，低音是否承担方向，音色变化何时变成段落事件，以及返回时哪一项参数被重新解释。

先读[键盘与管弦织体](examples/keyboard-orchestral-texture.md)。本章比较《水之倒影》《帆》《大海》和《牧神午后前奏曲》，把平行声部、持续低音、音区运动与乐器转移放在同一套检查框架中。

```text
Debussy Reflets dans l'eau texture
Debussy Voiles whole tone pedal
Debussy La Mer orchestration form
Debussy Prélude après-midi flute oboe transfer
德彪西 平行和弦 音色 层
```

本章没有复制受版权或未获许可的现代乐谱编码。LilyPond 例子全部是原创教学模型，使用 2.26.0；它们说明可迁移机制，不冒充德彪西原作。
