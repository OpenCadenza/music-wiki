# 作曲家与作品案例

按作品类型、音乐问题、时期和编制查资料。每个案例区分真实摘录、分析简化与自编教学模型；实际音符和结构位置是迁移风格特征的依据。

| 作曲家 | 入口 | 使用重点 |
| --- | --- | --- |
| J. S. Bach / 巴赫 | [巴赫](bach/index.md) | 动机、模仿、声部与调性进程 |
| W. A. Mozart / 莫扎特 | [莫扎特](mozart/index.md) | 乐句功能、织体、呈示与再现 |
| Maurice Ravel / 拉威尔 | [拉威尔](ravel/index.md) | 四重奏材料、节奏、音色与结构证据 |
| Ludwig van Beethoven / 贝多芬 | [贝多芬](beethoven/index.md) | 按体裁逐层检索；短专题内嵌谱例，技法与创作流程交叉链接 |
| Joseph Haydn / 海顿 | [海顿](haydn/index.md) | 主题处理与段落功能 |
| Frédéric Chopin / 肖邦 | [肖邦](chopin/index.md) | 练习曲的技术动作与音乐组织 |
| Claude Debussy / 德彪西 | [德彪西](debussy/index.md) | 键盘与管弦乐织体 |

分析章节放在各作曲家目录，按体裁或机制比较多部作品，内容较多时使用子目录；谱例内嵌正文；专题与通用理论互相链接。不把某个短例的特征宣称为整位作曲家的全部风格；自编例也不能作为历史事实的来源。
