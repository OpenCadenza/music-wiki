管弦章中的三个代码例为自编教学模型，说明机制而不冒充原谱。四重奏例只转录明确标注的声部和小节；研究中的全曲分析不等于代码已覆盖全曲。

用这些材料创作时，先说明迁移的特征，再根据编制、调性、音区与乐句职责重新写谱，最后编译、看谱并复核。
