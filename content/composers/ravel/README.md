# Maurice Ravel

Ravel (1875-1937) is most useful to a composition agent as a set of bounded
compositional procedures, not as a one-word preset. In this collection,
"Ravel-like" means that the plan makes a defensible choice about modal melody,
extended sonority, harmonic or registral planes, metric layering, orchestration,
and a formal boundary. Each choice should cite a work or a reviewed analysis.

Read in this order:

1. [Operational style profile](style.md) for the constraints and warning signs.
2. [String-quartet and cyclic-material analysis](string-quartet.md) for the
   ensemble most relevant to a new quartet.
3. [Analysis examples](examples/README.md) for short musical demonstrations.

Useful task queries:

```text
Ravel modal melody functional cadence
Ravel planing extended chord register
Ravel string quartet cyclic theme
Ravel timbre form orchestration
Ravel metric layering
```

Keep historical labels scoped. Ravel's music spans keyboard miniatures,
chamber works, songs, ballet, concertos, and orchestral transcriptions. The
absence of a feature in one work does not prove that it is alien to his style,
and a feature found in one late orchestral work is not automatically valid for
a string quartet.
