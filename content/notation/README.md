# 记谱与可计算事实

写谱先读 [ABC](../abc.md) 或 [LilyPond](../lilypond.md)；精确术语和检查边界见 [记谱卡](format-cards.md)。执行见 [脚本说明](../scripts.md)。

LilyPond 的 Staff、Voice、时值继承、relative 锚点是记谱机制；“独立声部”“终止”“可演奏”仍需音乐语境。PDF、MIDI、编译诊断与输入哈希分别记录。MIDI 的同音异名和声部信息不应当反推为原谱的确定事实。
