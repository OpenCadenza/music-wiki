# 曲式与功能 Form and function

读取 [主题与曲式卡](phrase-form.md) 选择功能；需要整体布局时读 [曲式与连贯](../form.md)。对位属于技法入口，赋格等体裁可从 [对位与模仿](../techniques/counterpoint/README.md) 交叉进入。

分析先定位材料、调性到达和终止，再给段落命名。八小节长度不充分证明 sentence 或 period。变奏需要主题与派生材料的对应；奏鸣曲需要呈示与再现之间的关系。

真实案例见 [莫扎特](../composers/mozart/README.md)。下级分类随资料增加调整，以稳定 ID 引用知识；不要复制正文到另一种分类。
