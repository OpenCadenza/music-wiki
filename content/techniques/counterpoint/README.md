# 对位、模仿与赋格

读 [写作与审查](practice.md)，再按需读 [种类对位与赋格卡](cards.md)。作品与短例从 [巴赫案例](../../composers/bach/README.md) 进入。

## 卡农 Canon

卡农是可核对的延时模仿关系，先规定进入间隔与移调规则，再测试同时发声。倒影需说明音程规则；终止若改变模仿，须注明严格关系终止的位置。三声部不能只检查相邻两组声部。

依据：[Rubin, Composing Canons](https://open.lib.umn.edu/musiccomposition/chapter/composing-canons/)，A–F 小节（CC BY 4.0）；此处为重新组织的工作说明。

## 赋格 Fugue

赋格呈示部、后续主题进入、插部和终止共同组织全曲。对题要以重复出现为证据；紧接需主题在结束前重叠进入。倒影、增值或假进入均非每首赋格必备项目。

依据：[OMT, High Baroque Fugal Exposition](https://viva.pressbooks.pub/openmusictheory/chapter/high-baroque-fugal-exposition/)、[Rubin, Composing a Fugue](https://open.lib.umn.edu/musiccomposition/chapter/composing-a-fugue/)，Subject / Exposition / Counter-Subject / Episodes / Stretto。不同教程的模型不能当成唯一历史规范。

## 创意曲 Invention

将短材料在两条可辨线条间发展，不强制所有段落都严格卡农，也不按“小型赋格”自动命名。比较实际主导声部、动机的完整/片段出现及终止。巴赫 BWV 772 的具体证据与编码出处见作曲家案例。
