# 终止四六和弦

<p class="doc-subtitle">终止四六在古典终止式中为何不是独立和弦而是属延留？它何时必须出现、何时被省略，又如何重塑属七解决与终止层级？</p>

在初级和声教学与机械的罗马数字标记中，**终止四六和弦（Cadential 6/4）**常被草率地标注为“主三和弦的第二转位（$I^6_4$）”。这一历史遗留的标记在音乐分析与声部写作教学中造成了深远的认知混乱：如果它在本质上是主和弦（Tonic），为何它总是出现在前属功能（Predominant）蓄势之后？为何它在强拍降临时不仅无法带来终结感，反而激发起向属和弦狂跌的巨大重力？更重要的是，为何它绝不能自行结束，而必须亦步亦趋地滑向原位属三和弦？

现代曲式理论与通奏低音历史研究（以威廉·卡普林 William Caplin 的曲式功能论、海因里希·申克 Heinrich Schenker 的对位还原论，以及 Open Music Theory 的功能低音框架为代表）彻底终结了这一混乱：**终止四六绝不是一个独立的主和弦，而是完全从属于属功能区（Dominant Zone）的重拍双重倚音（Double Appoggiatura over Dominant Bass）**。本文的核心问题在于：**终止四六的对位声部导向如何从根本上决定其“属功能延留”的本质？古典作曲家在曲式构建中究竟遵循何种结构逻辑决定其“必须出现”或“果断省略”？它又如何与属七和弦（$V^7$）精密咬合，确立完全正格终止（PAC）与半终止（HC）的层级权威？**

## 一、本质归属：从“假性主三和弦”到“属功能双重倚音”

要认清终止四六的语法地位，必须透视垂直音响堆叠与水平对位运动之间的本质分野。

虽然终止四六在垂直音高集合上由主调的三和弦音级构成（例如 C 大调中的 G–C–E，包含 $\hat{5}, \hat{1}, \hat{3}$），但它在声部织体中的行为完全遵循低音上方的不协和音处理法则：

```
【终止四六的声部导向与功能还原矩阵】
垂直音高构成 (C 大调)     音程关系 (相对于低音 G)     对位属性与解决倾向         属功能标记 (V 延留)
高音声部：E / mi (3音)  ─── 六度音 (6th)  ───────→  下行级进解决至 D (5音)  ─→  6 ──→ 5
中音声部：C / do (根音) ─── 四度音 (4th, 不协和) ─→  下行级进解决至 B (导音) ─→  4 ──→ 3
内音声部：G / sol (5音) ─── 八度音 (8ve, 倍加低音)─→  保持或顺势滑向 F (七音)─→  8 ──→ 7
低音声部：G / sol (属音)─── 原位低音基底 ────────→  强拍牢固驻留至属原位  ─→  低音 5 保持
```

### 1. 原位属音的重拍下锚与倍加禁忌
在终止进行中，低音到达属音（$\hat{5}$）标志着前属功能向属功能的交接完毕。无论上方声部如何运动，低音始终是作为属和弦的根音牢固下锚在强拍（Downbeat）或次强拍上。

更为关键的对位铁律体现在**倍加法则**中：在四部和声织体中，终止四六**几乎必然倍加低音属音（$\hat{5}$）**，而严禁倍加四度音（$\hat{1}$）或六度音（$\hat{3}$）。这是因为四度与六度均为依附于属音的不协和倚音，若发生倍加，在随后的平行下行解决中将不可避免地导致平行的纯八度或纯五度，从而破坏声部独立性（详见[《众赞歌终止式》](../../composers/bach/chorale/cadential-voice-clock-and-phase-decoupling.md)中对终止声部时钟的论述）。

### 2. 双重倚音的引力释放
在低音原位支撑之上，上方声部所谓的“主和弦音”全部作为倚音（Appoggiatura）或预备挂留音存在：
- **四度音（$\hat{1}$）**：在通奏低音传统与严格对位法中，低音上方的纯四度被视为典型的不协和音程，它必须严格下行二级解决至导音（$\hat{1} \to \hat{7}$，即 $4 \to 3$）；
- **六度音（$\hat{3}$）**：作为属和弦五音的不协和修饰音，必须顺应重力下行级进解决至超主音（$\hat{3} \to \hat{2}$，即 $6 \to 5$）。

因此，现代和声学将其准确记作 **$V^{6-5}_{4-3}$** 或 **$Cad^6_4$**。整个过程不是和弦之间的横向行进，而是**单一属和弦内部的装饰音延留（Dominant Prolongation）**。

## 二、微观对位咬合：$8-7$ 滑移与向心力倍增

终止四六在古典乐派中的至高地位，不仅在于其延留属功能，更在于它与属七和弦（$V^7$）之间存在着一种近乎完美的机械咬合机制：

依据 Open Music Theory（OMT）对“复合终止（Compound Cadence）”的分类，当六度与四度音下行解决为五度与三度时，负责倍加低音的八度音通常不会机械保持，而是**顺势下行级进至小七度（$\hat{5} \to \hat{4}$，即 $8 \to 7$）**。

这一微观声部滑移瞬间触发了多重引力爆发：
1. **属七三全音的瞬时激活**：四度音解决至导音（$\hat{7}$），倍加音滑移至下属音（$\hat{4}$），两者在属和弦内部构成了调性中最关键的三全音（Tritone）。这个不协和三全音的张力直接锁死了随后的主和弦归宿；
2. **两阶段动能梯级**：
   $$\text{前属蓄能 } (ii^6 / IV) \longrightarrow \text{重拍阻尼延留 } (V^{6-5}_{4-3}) \longrightarrow \text{三全音向心加速 } (V^7) \longrightarrow \text{终极闭合 } (I)$$
   终止四六提供了巨大的重音阻尼，将原本瞬间滑过的属和弦扩展为一个包含“延留缓冲”与“七音加压”的完整句法单元；
3. **高音声部的三种典型解决路径与终止层级**：
   - **导音解决路径（$\hat{1} \to \hat{7} \to \hat{1}$）**：四度音置于最高声部，下行至导音后强力反弹回主音，构成最刚健的完全正格终止（PAC）；
   - **超主音解决路径（$\hat{3} \to \hat{2} \to \hat{1}$）**：六度音置于旋律声部，自三音经超主音优雅滑落至主音，构成歌唱性 PAC；
   - **八度跳跃与弱化路径（$\hat{5} \to \hat{4} \to \hat{3}$）**：旋律声部由八度音顺势进入七音并解决至主三音，往往用于刻意构建不完全正格终止（IAC），留存张力（详见[《乐句扩展》](../structure/phrase-expansion-and-structural-skeleton.md)）；
4. **小调中的半音化下沉重力**：在同主音小调中，六度音为小六度（$\hat{6}\flat$），四度音为主音（$\hat{1}$）。在解决过程中，小六度向下移动半音至属音（$\hat{5}$），这种半音化滑移赋予了小调终止四六无与伦比的悲剧性重力；
5. **加兰特历史源流与双重终止**：在意大利通奏低音（Partimenti）传统中，费纳罗利（Fenaroli）与富尔诺（Furno）常采用被称为“双重终止（Double Cadence）”的四阶段图式：$5/3 \to 6/4 \to 5/4 \to 5/3$。古典大师继承并提炼了这一传统，将其精简为如今高度聚焦的 $V^{8-7}_{6-5 \atop 4-3}$，完成了从外声部填充物到核心句法杠杆的飞跃。

## 三、结构出现法则：何时必须出现 vs. 何时可以省略？

在维也纳古典乐派的实际创作中，终止四六并非机械地附着于每一次终止。作曲家依据曲式层级的不同，严格施行有差别的使用策略：

```
【终止四六的结构出现与省略决策树】
┌─────────────────────────────────────── 终止四六决策树 ───────────────────────────────────────┐
│                                                                                              │
│                   [当前终止处于何种曲式层级？]                                               │
│                                │                                                             │
│       ┌────────────────────────┴────────────────────────┐                                    │
│       ▼                                                 ▼                                    │
│  【宏观结构性终结】                               【轻快流动性收束】                         │
│  • 呈示部副部根本终止 (EEC)                       • 4小节紧凑乐句内部半终止                  │
│  • 再现部终极完满终止 (ESC)                       • 谐谑曲/轻快快板小乐段                    │
│  • 协奏曲华彩段切入点                             • 弱化乐句延续句过渡                       │
│       │                                                 │                                    │
│       ▼                                                 ▼                                    │
│  【必须出现 (Obligatory)】                        【果断省略 (Omitted)】                     │
│  • 采用复合终止 (Compound Cadence)                • 采用简单终止 (Simple Cadence)            │
│  • 强制插入重拍 Cad⁶₄ 形成重音悬念                • 直接采用 ii⁶→V 或 IV→V                   │
│  • 彻底拉大属功能时间跨度                         • 避免重音刹车，保持前进动量               │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. 何时必须出现（Obligatory Cadential Marker）
- **奏鸣曲式宏观结构标点**：呈示部副部结尾的根本收束（Essential Expositional Closure, EEC）以及全乐章再现部的最终收束（Essential Structural Closure, ESC）之前。此时必须向听众明确宣告调性航程即将停靠，必须调动重型 $Cad^6_4$ 实施强力减速制动；
- **古典协奏曲华彩段进入点（Cadenza Entry）**：管弦乐全奏在冲向高潮的最后一击，必然以特强（ff）敲出 $Cad^6_4$，并在低音属音上长久延长（Pause/Fermata），高声部解决被延宕，为独奏家的即兴炫技打开通道；
- **复合乐段中的后乐句完满终止（PAC）**：为了在层级上彻底确立后乐句对前乐句的统摄地位，后乐句 PAC 几乎无一例外采用包含 $Cad^6_4$ 的复合终止，以构筑无可置疑的终结权威（详见[《复合乐段》](../structure/compound-period-hierarchical-syntax.md)）。

### 2. 何时果断省略（Omission in Simple Cadences）
- **轻快流动性的简单半终止（Simple HC）**：在乐段前半程的前乐句（Antecedent）中，为了保持音乐的开放性与前进动量，常直接以 $ii^6 \to V$ 或 $IV \to V$ 结束，故意省略 $Cad^6_4$，避免过早产生沉重的刹车感；
- **快速动力的谐谑曲或微型乐节**：当小节节奏极快或乐节仅有 2–4 小节时，强行插入两拍以上的四六延留会破坏其急促轻盈的体裁性格；
- **动机纺织（Fortspinnung）与流动过渡**：在展开部或过渡段中，音乐需要持续释放动能，此时终止多采用直接进入的属和弦，防止行进动能被提前阻断；
- **与终止逃逸技术的区别**：必须明确，省略终止四六是追求“轻盈直接”，而[《终止式延后》](../structure/cadential-evasion-and-temporal-expansion.md)中讨论的规避终止（Evaded Cadence）则是蓄意在最后一刻抹消预期的 PAC，两者在美学目标与句法机制上完全正交。

## 四、经典乐谱实据核验与声部对位还原

### 1. 莫扎特《A大调第11钢琴奏鸣曲》K. 331 第一乐章主题（mm. 1–8）
依据本地 Humdrum ABC 谱源与 Open Music Theory 的和声缩编谱（k331-reduction.ly），莫扎特在此处为“半终止与完全终止中的终止四六”提供了教科书般的对比：
- **前乐句复合半终止（m. 4）**：
  - 前半拍为主和弦向二级六和弦行进（$I \to ii^6$，低音达 D2），后半拍低音明确跃至属音 E2；
  - 右手声部在属音低音上方打出六度音 c♯² 与四度音 a¹，随后平稳下行解决至五度音 b¹ 与三度音 g♯¹（形成清晰规范的 $V^{6-5}_{4-3}$ 半终止）；
- **后乐句复合完全正格终止（m. 8）**：
  - 第 7 小节低音经升 F、升 G、A 至 D 级进完成前属蓄势；
  - 第 8 小节强拍低音 E2 上，右手和弦为 E4–A4–c♯5（由属音上方八度、四度、六度构成的经典 $Cad^6_4$）；随后四度音 a¹ 下行至 g♯¹、六度音 c♯² 下行至 b¹，倍加的八度音 e¹ 顺势滑向小七度 d¹（完整构成 $V^{8-7}_{6-5 \atop 4-3}$）；
  - 最终在第三拍双手干净收束于 A 大调原位主和弦（左手低音跳进至 A1，右手高音稳稳落于主音 a¹），达成绝对权威的完全正格终止（PAC）；
  - 其微观声部时钟与层级对位映射如下表所示：

```
【莫扎特 K. 331 第 8 小节复合终止微观声部时钟映射】
节拍位置 (6/8)    低音声部 (Bass)    内音声部 (Alto/Tenor)     高音声部 (Soprano)      和声功能语法
第 1–2 拍 (重音)  E (属音牢固下锚)   E (八度倍加) / A (四度倚音) C# (六度歌唱倚音)       V⁶⁻⁵₄⁻³ (终止四六延留)
第 3 拍 (过渡)    E (属音原位持续)   D (八度顺势滑向小七度) / G# B (六度平稳下落至五度)  V⁷ (属七三全音加压)
第 4–5 拍 (着陆)  A, (主音强劲跳进)  E / A (主三和弦对位充填)   A (主音完满落定)        I (PAC 终极收束)
```

谱例待补：莫扎特《A大调第11钢琴奏鸣曲》K. 331 第一乐章 mm. 1–8

### 2. 莫扎特《C大调第15钢琴奏鸣曲》K. 545 第一乐章：主部省略与副部强制
- **主部第 4 小节（简单半终止省略四六）**：
  - 旋律轻盈流动，低音由 $I \to IV \to ii^6$ 直接切入 $V$，完全省略终止四六，使音乐自然滑向过渡段；
- **副部根本终止 EEC（mm. 22–26）**：
  - 在经历长达数小节的十六分音符下行跑动后，第 24 小节强拍在副调（G 大调）属音 D3 上以重拍进入 $Cad^6_4$（高音声部盘旋六度音 B4 与四度音 G4）；
  - 第 25 小节和声转化为整整一小节的属七长颤音（高音 a2 上的属音颤音）；
  - 最终在第 26 小节强拍爆发出无可动摇的 G 大调 PAC（呈示部根本终止 EEC）。若无第 24 小节终止四六的强力拦截与减速阻尼，前方的长程十六分音符狂飙将无法获得稳固的结构着陆。

谱例待补：莫扎特《C大调第15钢琴奏鸣曲》K. 545 第一乐章 mm. 22–26（副部 EEC）

### 3. 莫扎特《G大调第5钢琴奏鸣曲》K. 283 第一乐章 mm. 5–10
在加兰特风格与古典曲式的交汇处，终止四六还承担着将线性图式转化为结构终止的关键使命（详见[《终止图式》](../structure/cadential-prinner-and-structural-closure.md)）：
- **图式启动与低音变异（mm. 5–8）**：第 5–6 小节 Prinner 启动，高音声部自 e² 下行至 d²，低音顺次下落至 C 与 B；在第 7–8 小节十六分音符展开后，低音脱离原型级进轨迹；
- **终止四六重音插入与解决（mm. 9–10）**：第 9 小节低音坚决跳向属音 D3，右手在属音上方展开十六分音符分解琶音跑动，在强拍形成清脆的终止四六延留（低音 D 上方叠置四度音 G 与六度音 B），并在弱拍利落解决为原位属七和弦；第 10 小节强拍双手坚决落在原位 G 大调主和弦上，达成完全正格终止（PAC）。

本段谱例见[《加兰特图式在古典句法中的曲式功能整合》](../structure/galant-schemata-and-formal-functions.md#score-mozart-k283-i-mm1-10)（莫扎特 K. 283 第一乐章 mm. 1–10，mm. 5–10 为终止四六插入与解决的位置；同一片段全库只保留一份）。

## 五、对现代器乐写作与曲式分析的启示

深入理解终止四六的和声对位本质，为古典风格分析与器乐曲式写作确立了清晰的实践法则：

1. **彻底破除“主和弦第二转位”的伪概念**：在和声分析与古典风格创作中，必须将终止四六视为属功能区（Dominant Zone）内部的重拍双重倚音修饰，绝不可将其作为主功能（Tonic）调度；
2. **曲式层级决定终止权重**：在构建乐句收束时，应依据结构权重严格区分终止形态：内部过渡乐句可采用直接属和弦（Direct V），宏观核心收束（如副部 EEC 或再现部 ESC）则须强制引入 $Cad^6_4 \to V^7 \to I$ 构筑终结权威；
3. **严格遵守对位下行禁令**：在安排四部和声声部导向时，终止四六的六度音与四度音严禁向上反跳，必须顺应引力平稳下行级进（$6 \to 5$ 与 $4 \to 3$），配合八度向七度的平滑滑落（$8 \to 7$），方能释放古典乐派纯正严密的向心闭合动力；
4. **节拍重音对齐准则**：终止四六必须落在相较于其后属和弦更强的节拍位置（如 4/4 拍的第一拍或第三拍，6/8 拍的第一拍或第四拍），绝不在弱拍突兀插入四六和弦，确保其重音阻尼的听觉心理效应如期生效；
5. **严守低音属音倍加法则**：在四部和声织体中，终止四六必须严格倍加低音属音（$\hat{5}$），严禁倍加四度倚音或六度倚音，杜绝在随后的下行解决中诱发平行五八度的风险（详见[《众赞歌终止式》](../../composers/bach/chorale/cadential-voice-clock-and-phase-decoupling.md)）。
