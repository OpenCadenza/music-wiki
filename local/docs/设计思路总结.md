**让 Agent 像音乐学者一样自主构建知识库**

这个工作流的出发点，是把知识库建设理解为一种持续的音乐研究与著述活动。知识库的价值来自作者对音乐的理解：读过真实资料，发现值得解释的问题，形成自己的判断，再把这些理解写成别人能够读懂、能够用于学习与创作的文章。因此，工作流首先要建立真实阅读与文章写作之间的联系，让每篇文章都有知识输入，也有消化、推理和表达。

在这个设计中，资料为研究提供起点，研究问题在阅读中逐渐形成。音乐学者可以从教材中的一个概念、论文中的一种解释、作品中的一个现象，或不同材料之间的联系与分歧出发，发现值得讲述的选题。随着理解加深，选题可以改变，论点也可以调整。一篇文章可以讨论多部作品，同一部作品也可以支持不同问题的研究。这样的探索不需要预先限定作曲家、体裁或主题，也不应由现成谱例的多少决定知识库先写什么。

文章体现的是作者理解后的重新组织。资料中的概念与观点，需要经过比较、联系和推导，才能成为清楚的解释。音乐学者可以提出自己的归纳，形成鲜明的观点，但需要分清资料作者的说法、实际音乐现象和自己的推论。真实依据与独立思考在这里共同成立：主要论点应当有支撑，作者也应当拥有解释和著述的空间，不必为每一句分析寻找文献中的同一句话。

为了让这种研究持续进行，各类 Agent 的行为围绕不同责任展开。音乐学者承担知识判断，决定什么问题值得研究、还缺少什么材料，以及文章最终需要说明什么。它获得的是探索自由，而不是一份预先写好标题、结论和章节的填空任务。它应当主动阅读、提出问题、补充研究、调整论证，并在形成理解后自主完成文章。文章的位置和结构也由内容决定，既可以提炼跨作品、跨语境的共性，也可以解释某位作曲家、某种编制或某类风格中的具体做法。

资料收集助手为这种探索提供可靠支撑。音乐学者提出研究需求，助手负责寻找、取得、定位和整理材料，并把实际取得的内容、可读范围与缺口交代清楚。助手的概述可以帮助发现线索，但音乐学者仍须亲自阅读用于立论的资料。这样的分工让学术判断留在研究者手中，同时减少搜索、下载、格式处理等工作对思考的打断。

谱例的交付责任也集中在资料助手一侧。助手需要确保交付谱例真实、正确并符合要求，不能把未经确认的材料交给音乐学者自行验收。音乐学者可以依赖这一交付，集中精力理解音乐和组织论证，无需重复检查谱例的正确性与格式要求。如果找不到满足要求的谱例，助手应当如实报告，学者可以保留占位。这里需要区分缺少展示材料与缺少知识依据：谱例暂缺可以留下明确缺口，中心论点尚未得到理解和支持，则仍需继续研究。

资料初步整理承担的是研究开始前的准备责任。它让已有材料便于发现和阅读，并保留原件与整理结果之间的关系。正式研究开始后，这种整理能力由资料助手继续承担，使新增材料能够及时成为共同研究基础。资料库因此具有持续生长的性质：新资料不仅服务于提出请求的学者，也能被其他学者阅读，并启发新的选题。资料的使用地位取决于内容和实际可用状态，不取决于它在哪一轮被取得。

多名音乐学者拥有探索自由后，还需要能够了解彼此的研究。Agent 之间的直接沟通用于解决当前问题，共享研究状态则帮助大家理解全局。每位学者公开自己正在研究什么、涉及哪些资料、已有怎样的成果和缺口，同行便能主动发现重叠、共享材料、建立联系或调整角度。这种协作依靠相互了解和直接交流，不要求主控事先划出严格的学术边界，也不把每一个选题都送去审批。

主控的行为重点，是维持这套研究活动的连续性。它提供共同目标、资料入口、写作原则和清楚的责任划分，协调共享成果与文件，处理运行中断和协作冲突，并确保各项工作能够收尾。具体知识判断尽量由实际研究问题的学者作出，资料交付由助手完成，常规协作由 Agent 之间自行解决。这样，主控可以把注意力放在整体方向与运行秩序上，而不必逐篇指定内容、逐步转述消息或替每个 Agent 作决定。

全程自主的关键，是让 Agent 拥有完成一项工作的责任，而不仅仅是执行一个孤立动作。音乐学者发现问题后，应能自行推进到补充资料、形成论证和完成文章；助手收到需求后，应能自行推进到取得、整理和明确交付；遇到缺口时，各方应知道如何继续研究、调整范围或如实记录。只要问题仍在既定授权与职责范围内，就由团队继续处理，减少对用户反复确认的依赖。用户主要决定目标、原则、边界和阶段性要求。

这种自主性还需要持久的研究状态作为支撑。资料已经取得、已经整理、学者已经阅读、文章已经成稿、编辑已经复读，是不同的进展，不能笼统合并成“完成”。清楚保留这些状态，才能让其他 Agent 接手，也才能在中断后从实际进度继续。研究记录和成果历史因此属于知识生产的长期资产，它们使自主工作具有连续性，也让用户能够看见文章究竟怎样形成。

编辑复读安排在整批文章形成之后，从整体上审视理解、论证、关联与可读性。这样的安排保留了单篇探索的连贯性，也让编辑能够发现跨篇重复、概念冲突、解释不一致和相互补充的机会。修订仍沿着原有责任展开：文章的理解与表达由学者处理，谱例问题由资料助手处理。编辑帮助成果趋于成熟，同时避免把质量控制变成重复验收或无止境的细节核对。

知识正文与生产过程也需要保持清楚的分工。正文集中讲音乐，让读者理解材料、结构、音响及其关系；来源、许可、研究进度与协作记录在正文之外保存。知识创作与平台工程维护同样保持边界，使团队能够持续著述，而不会在解决内容问题时不断扩展到工具链和站点改造。

整个设计最终服务于一种能够自主延续的研究秩序：真实资料不断进入共同空间，音乐学者从中发现问题，资料助手提供可靠支撑，文章在理解中形成，编辑再从整体上改善成果。衡量这套工作流的标准，是它能否持续产生有依据、有观点、读得懂的音乐文章，并让读者和创作 Agent 获得更深入的理解与更有把握的音乐判断。
