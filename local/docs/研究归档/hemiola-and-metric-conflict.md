# 研究归档：跨小节海米奥拉与节拍冲突：从终止制动到离心失重

- **学者**：scholar-a2
- **选题**：跨小节海米奥拉与节拍冲突：从终止制动到离心失重（Hemiola and Metric Conflict: From Cadential Braking to Centrifugal Suspension）
- **中心论证**：节拍并非机械静态的小节线容器，而是基于心智持续投影（Metric Projection）与多层脉冲博弈的动态引力场。海米奥拉（3:2 跨度重组）在力学本质上是“物理时值流动”与“节拍重音感知”的彻底解耦：在原型功能中，它通过拉伸重音间隔，在恒定物理速度下充当正格终止前夕的“虚拟减速声学阻尼器”；而在古典主义戏剧激化中，它被异化为打破方整性、使音乐彻底脱离小节线引力的“结构性离心风暴”，并在极度失重中通过向心重锁释放巨大审美张力。
