- 底本：CCARH MuseData（kern / md2）与 Humdrum kern→ABC 链路，全部自编码转写；OpenScore CC0 用于交叉核对。
- **核对方法**：kern 组 MIDI 音高集合逐谱表回比对；md2 组按分谱音高多重集 + 逐小节 `|`（barcheck）兜底；每块围栏都有底本定位与核对记录（`local/workbench/scores/score-beethoven-r6/R6-交付与核对记录.md`、`local/workbench/tools/score-r6/`）。
- 本轮抓出并修正的真实缺陷：
  1. md2 降号写作是 **`f` 后缀**（`Ef6`=E♭6），只认 `-` 会静默丢音 → K.467 I m.18–19 的 E♭6 曾被吞，已修正重出，并在解析器加「未知音高记号直接报错」；
  2. 自写 abc2ly 绝对八度整体低一个八度（LilyPond `c'`=MIDI 60）→ MIDI 回比对抓出并修正；
  3. LilyPond 自带 abc2ly 对多声部 K.545 会拆小节 → 改用 hum2abc + 自写转换器；
  4. 一处手抄漏音（K.545 m.7）→ 新增 `diff_fence.py` 正文围栏 vs 已验证草稿逐行比对。
- 新增底本登记：`local/origin_resources/sources/ccarh-musedata-beethoven-symphonies/`（7 个 md2 + manifest + README）、`sources/dcml-mozart-sonatas/`（DCMLab 音符表，CC BY-NC-SA 4.0，**只作核对、不入发布**）。
