## 2. 选题方向（待谱源盘点后细化）

优先补第一、二轮未覆盖的作曲家与体裁：

- 作曲家：莫扎特（交响曲/协奏曲/歌剧）、海顿（四重奏/交响曲）、舒伯特（艺术歌曲/室内乐）、勃拉姆斯（交响曲/室内乐）、肖邦、德彪西、斯特拉文斯基、巴托克等。
- 体裁/编制：钢琴四重奏、弦乐三重奏、管乐八重奏、协奏曲、歌曲二重奏、协奏曲 gross 等。
- 技法/风格：变奏曲式、回旋曲式、赋格、协奏曲协奏原则、巴洛克/古典协奏曲风格、浪漫性格小品。
- 记谱：移调乐器记谱、演奏法记号与实现。

每篇必须能落到具体小节与可核底本；无源题目降级或替换，不硬写。

## 3. 每篇门禁（沿用第二轮）

1. H1 2–8 字 + 单行 `<p class="doc-subtitle">`；frontmatter `title` 与 H1 一致。
2. `node local/workbench/tools/check_article_acceptance.mjs <片段>` 通过。
3. `node scripts/validate-content.mjs` 通过。
4. `local/workbench/tools/check_notation_fences.mjs` 全部编译。
5. `provenance/<同路径>.md` 引用表/谱例表非空；未核实写“待补/未确认”。
6. `local/docs/研究归档/<slug>.md` 同名存在，状态按复读更新。
7. 正文无内部代号、`local/` 路径、GM 编号、源文件行号、生产语境。

## 4. 提交与推送

- 主控串行 `git add/commit`，每篇一条；只推 `scholar-agent-dev`。
- 第三轮结束：更新 `完成报告.md`、`进度日志.md`、`中止与交接.md`，推送。
- 第四轮结束：全库 QA + 最终推送。
