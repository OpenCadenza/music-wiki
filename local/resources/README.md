# 阅读资料库

本库供音乐学者发现、阅读和调用资料。预备轮与正式轮新增材料同等可用；资料卡和助手概述不能代替实际阅读。原件保存在相邻的 origin_resources，正文文章另在 content 中维护。

## 先从这些入口阅读

- [全部来源与文本入口](catalog/parts/text/index.md)：26类来源，含教材、论文、背景、乐器资料、标注与谱源。
- [HTML整理正文](text/organized-html/README.md)：去掉网站导航的论文、介绍与乐器资料，保留原网页映射。
- [OCR 文献与图像目录](catalog/ocr-conversions.md)：真实转换状态、页数、Markdown与原件链接。
- [OCR验收与限制](catalog/parts/ocr/index.md)：物理页记录核对、图像引用检查及空文字结果。
- [已解包谱源入口](scores/source-packages/README.md)：Kern与DCML原生谱文件。
- [完整加工索引](catalog/index.json)：机器可读的来源与处理状态。

## 阅读与谱例

OMT教材、论文、版本导言与乐器资料可以直接启发选题。标注数据需要结合数据字典和原谱；它们不是唯一正确的音乐分析。Kern、ABC、MusicXML、LilyPond与原谱图像的入口见来源卡和谱包目录。

PDF／图片由用户指定 EverythingMarkdown（PaddleOCR-VL-1.6）转换。原谱OCR保留文字和图像，不保证识别音符；需要代码时查可靠谱源或处理目标片段。

## 已知缺口

- 历史收集偏重贝多芬，不代表正式轮优先；学者可从其他材料选题，再由资料助手按需补充。
- OMT2导出、部分来源下载和未缓存全文的历史缺口，见各来源卡。
- 部分HTML内文图像不在原库，整理正文明确标注缺失；这类材料不能冒称图文齐全，正式研究可按需补图。
- OMT旧版仍有一条 sonata.html 指向未取得目标；PDMX README的PDMX.png未取得，保持缺失状态。
- 大型OpenScore包保留目录，大型PDMX归档不盲目展开；已知原件始终可从原始库追查。
- OCR作业完成不保证文字识别。op98-autograph-page-002.jpg返回文字为空，保留服务输出并提供原图阅读入口，标为converted_image_only。

旧Agent生成文章、自编模型和历史日志不在默认学术阅读入口中。
