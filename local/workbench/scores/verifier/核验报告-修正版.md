## 1. 核验方法（可复现）

1. **不靠人工推八度**：把被测文件里的音乐变量原样式贴进临时文件，用 LilyPond 自身的 `\displayLilyMusic` 输出 `\absolute{...}`，得到**绝对音高**（已用 `\relative c' { c d e f g a b c }` → `c' d' e' f' g' a' b' c''` 校准：绝对模式下 `c'` = 中央 C）。
   临时件：`local/workbench/scores/verifier/tmp/*_pitch.ly`。
2. **MIDI 逐音**：重新用 `lilypond --pdf` 编译三件被测文件，再用自写工具 `local/workbench/scores/verifier/tools/midi_dump.py <mid> <每小节拍数> <弱起拍数>` 按小节导出每个音的 (起始拍, MIDI 号, 时值)，与被测 `.ly` 的绝对音高互相印证。
3. **源文件结构化解析**：
   - Haydn：Mutopia `hob-xvi-27-iii-presto.ly` 抽 mm.1–8 原样编译取绝对音高（源为 2.16 语法、`-|` 记号与荷兰语音名，摘录时只删 `-|`、改用 `\language "nederlands"`、`\Treble`/`\Bass` 改为变量赋值，音名/八度/时值/和弦一字未动）。
   - Mozart：ABC（Humdrum kern）逐 token 解出音高与附点；MusicXML 用 `musicxml_dump.py` 按 `<measure>` 导出；另用**谱面扫描图** `Graphics/form/k283.png` 做像素级复核（见 §3.4）。

4. **音域体检**：按 A0–C8（21–108）、小提琴 ≥G3（55）、中提琴 C3–C6（48–84）、大提琴 C2–C6（36–84）逐音检查。

### 3.4 八度争议的谱面像素复核（关键证据）

- 通行 m.1 的低音琶音（x≈396–696，共 6 个符头）：可单独识别出 5 个，其中心 y≈343.9 与 y≈324.9 交替出现——前者是**最线上方一间＝B3**，后者是**最线上方第一条加线（C4）之上＝D4**；首音与 C4 加线被符梁粘连未能单独识别，按 G–B–D 琶音形态推断为 G3（y≈365，最线下方一间）。
  **反证**：若为 G2 B2 D3，符头应落在 y≈431.5 / 412.5 / 393.5，即谱表下半部，与实测位置相差 3–6 个半线距，完全不符。

- 通行 m.7 的三个低音和弦在放大图中呈**相邻三度叠置**，上声部最高只到「最线上方第一条加线」高度＝C4；若上声部为 C5，应再高出约两个半线距（图面上不存在）。
- 结论：**G3/A3/F#3 低音区为真，被测件的 G2/A2/F#2 与 A3+C5 为错**。三份依据（ABC、MusicXML、谱面）互相印证。

### 10.4 Op.74 m.9 第 9 个十六分采用 E♮5 是否可接受 —— **可接受，建议保留 E♮5**

本轮**找到了第三方依据**，但它站在 E♭ 一边，所以需要把证据摆清楚：

| 依据 | 该音（m.9 十二个十六分中的第 9 个，onset = 3 个四分拍） | 性质 |
|:--|:--|:--|
| DCML `n10op74_01.notes.tsv` | **E♮5**（midi 76，tpc 4） | 结构化主源 |
| DCML `MS3/n10op74_01.mscx`（**未校订原始件**） | **E♮5**，`<Accidental subtype="accidentalNatural">` | 关键：证明还原号**不是**校订阶段加的，digitize 时就有 |
| DCML `reviewed/n10op74_01_reviewed.mscx` | **E♮5**，同上 | 已校订 |
| **原始 kern** `local/resources/scores/source-packages/beethoven-score-sources/beethoven-string-quartets-main/…/quartet10-1.krn` 第 73 行 | **E♭5**：`16ee-\LL`（显式降号） | 第三方（ABC 的上游，**与 DCML 独立**） |
| kern ABC（由上一行转换而来） | Eb5（`e` 无还原号，按 K:Eb 取降） | 与上行同源，不独立 |

三点判断依据（因此仍采信 DCML）：
1. **两份 DCML 文件（含未校订的 MS3 原始 digitize）都带显式还原号**——不是校订者事后编辑出来的，说明 DCML 的依据谱面上印着还原号。
2. **结构上的八度移位论证**（本轮新增）：把 m.9 的十二个十六分排开是
   `G4(连)·F4·**E♮4**·F4 | **E♮4**·F4·G4·F4 | E?5·F5·G5·F5`
   后四音 `E–F–G–F` 正是前四音 `E–F–G–F` 的**原位八度移位**；而前一组首音 E♮4 是所有源（kern 的 `16en`、DCML 的两个文件）都同意的。级进模进的八度移位在同一小节内改为异名音（E♭5）会破坏这个模进，因此 E♮5 更可能是原谱读法。
3. kern 的 `16ee-` 是明确的相反证据，不能忽略：**这确实是两份权威编码之间的 1 比 1 冲突**，本地无法再找到第四份独立依据（仓库内 Op.74 第一乐章只有 kern 与 DCML 两个谱源谱系；`beethoven-project` 下的 op74 文件都是文字/分析稿，不含音符）。

**处置建议**：保留现在的 E♮5；在被测文件注释里加一行「本音 kern 记 E♭5、DCML 记 E♮5，此处采信 DCML（理由：MS3 原始件即带还原号 + 八度模进）」，并在文章正文避免以这一音的半音性质立论（例如不要据此说「此处有半音阶经过音」）。若日后拿到 NMA / Breitkopf 影印，以影印为准。
