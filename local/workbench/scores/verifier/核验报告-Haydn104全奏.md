## 4. 圆号移调：核心裁决

### 4.1 事实

1. **MusicXML 显式声明**：`D Horn 1/2` 的 `<transpose>` 为 `chromatic=-10`、`diatonic=-6`，即**记谱音下移一个小七度 = 实音**。故 `written C4 → 实音 D3`，`written C5 → 实音 D4`。m.33–40 的 horn 1 = 记谱 C5（实音 D4），horn 2 = 记谱 C4（实音 D3）。
2. **kern 是实音（concert pitch）转写，不是记谱音**。判定依据（三条独立证据）：
   - 与 MusicXML 逐小节比对，**只在实音口径下相等**：Corno I 125/127 小节完全相等、**0 个"差八度"小节**；Corno II 106/114；Tromba I 96/103；Timpani 79/79。若把 kern 当记谱音下移，则整段会系统性地差一个八度，不可能达到这种吻合度。
   - 全乐章唯一出现"源间差八度"的地方是 **m.267–271 的 Corno II**——而 kern 文件头第 11 行恰好注明 `!! Old notation for horns m.267-71.(Transposed above written pitch rather than below.)`，即转写者在那一处改用了另一种八度叠法。这条注释反证了**其余各处都是把记谱音折算成实音**的。
   - 同一批铜管/移调乐器都呈实音：Tromba I m.33 = D5，而 XML 的 D Trumpet 1 记谱 C5（`transpose +2` → 实音 D5）；Clarinetto 1 in A m.33 = F#5，XML 记谱 A5（`transpose −3` → 实音 F#5）。**18 个声部一个不差**。
3. 因此 `.ly` 第 22–24 行"按 kern 的 **written** 音收录（Corno 1 = written D4、Corno 2 = written D3）"**前提错误**：kern 给的 D3/D4 就是**实音**。

### 4.2 回答设问

> **D 调圆号 written D3/D4 = 实音 A3/A4 还是实音 D3/D4？**

**两个选项都不是。** 正确口径：

- D 调圆号的记谱音**比实音高一个小七度**（`written = 实音 + 10 半音`；等价的说法是 `written C = 实音 D`）。任何 D 调圆号，**记谱 D 一律对应实音 E**：
  - **written D3 → 实音 E2**
  - **written D4 → 实音 E3**
- 想得到**实音 D3/D4**，必须写 **written C4/C5**（XML 正是这么写的）。
- "**实音 A3/A4**"不属于任何 D 调圆号惯例：D 调圆号里实音 A 对应的是 written G。这个选项可以直接排除。

### 4.3 kern 与 XML 谁更可信

- **实音层面：两源等价，互为印证**（本段 18 个声部 × 8 小节逐音相等，无一处差八度）。生产者说的"差八度层"**不存在**——那是把 kern 的实音误标成 written 之后，与 XML 的 written C5 相比较产生的错觉。
- **记谱层面：XML 更可信**。它把 written 与 sounding 分开、并显式给出移调量，可以直接生成圆号分谱；kern 是全曲实音转写，**绝不能直接贴到移调谱表上**。
- 生产者括号里"XML 写作 written C5（**实音 D5**）"也错了：written C5 的实音是 **D4**（下移小七度），不是 D5。

### 4.4 因此 `.ly` 的圆号行是什么状态

`.ly` 第 71–88 行把实音 D4/D3 直接写在 `instrumentName = "Corno I/II in D"` 的谱表上，且**没有 `\transposition`**（全文 `transposition` 出现 0 次）。后果分两层：

- **MIDI/播放：对**。没有移调，D4/D3 就按实音 D4/D3 发声，与两源实音一致。
- **谱面：错**。这是一份标着"In D"却没声明移调的圆号谱——圆号手看到 written D4 会吹出实音 E3，整条线低了一个八度又错了一个音级。渲染图里 Corno II 掉到五线谱下方三、四条加线的位置，正是"把实音当记谱音"的直观症状。

**修法（二选一）**：
1. 正规做法：加 `\transposition d`（LilyPond 中表示 written c′ 发实音 d，即下移小七度），音符改写为 **c″（C5, horn I）/ c′（C4, horn II）**；
2. 若坚持保留实音数字：把谱表名改成 `"Corno I in D (sounding)"` 之类，并显式说明本谱为实音记谱，去掉"In D"的移调暗示。

### 6.3 低音提琴 D1 的问题

- 但四弦低音提琴最低音为 **E1**，D1 需要 C 扩展或五弦；且 `.ly` 未用 8vb 记号，谱面上这一行掉到低音谱表下方四、五条加线，既超域也不像一份可用的低音提琴声部。
- **建议**：记谱按低音提琴惯例处理——实音 D2（=cello 同度、实际差八度发声）或加 `\set Staff.ottavation`；无论哪种，都应在注释里说明"源把 Cb 记在 cello 下八度，实音 D1 超四弦下限"。这一项**不影响本段论证**（D 踏板的八度叠置在 cello 上已经写清），但会让"音域自查通过"的说法站不住。
