### 2.2 S2-E2 — Brahms Op.90 III mm.1–8（大管长音层 + 大提琴主题）—— **不通过**

**权威源**：`downloads/brahms90/`（espace-midi.com, J.F. Lucarelli, Ver A / 2017），核对文件 `BrahmsSYMPH3M3/BrahmsSYMPH3M3_music-Fagotto_I_II.ly`、`…-Violoncello.ly`，并交叉核对同工程 `BrahmsSYMPH3_conductor.ly` 生成的总谱 PDF（152 页）。

**（a）大管：与底本一致 ✅**

底本 m.1 起：`c4 \p r8 | f4 r8 | c4 r8 | f4 r8 | b,4 r8 | c4 r8 | aes'4 r8 | g8 c bes`
（`\relative c` → 首音 C3；即 C3 F3 C3 F3 B2 C3 A♭4 | G4 C4 B♭3）

交付件：`c4 | f4 | c4 | f4 | b,4 | c4 | af'4 | g8 c bf` —— 音高、时值、休止（四分音符 + 八分休止）**完全一致**。大管音域 B2–A♭4，合规（B♭1–E♭5）。

**（b）大提琴：整体低一个八度 ❌ + 2 处八度断裂 ❌**

底本 `ScMcVioloncello = \relative c' {…}`（首音 **C4**），并在此处 `\bassToTenor`（换次中音谱号）。逐小节对照：

| 小节 | 底本（绝对音高） | 交付件 | 判定 |
|---|---|---|---|
| 弱起 | C4 D4 | C3 D3 | 低八度 |
| m.1 | E♭4 | E♭3 | 低八度 |
| m.2 | G4 F4 D4 ／ C4 D4 | G3 F3 D3 ／ C3 D3 | 低八度 |
| m.3 | E♭4 | E♭3 | 低八度 |
| m.4 | **B♭4 A♭4** D4 ／ D4 E♭4 | **B♭4 A♭3** D3 ／ D3 E♭3 | **B♭4 未降八度、A♭3 降了 → B♭4→A♭3 变成"全音+八度"的断裂** |
| m.5 | F4 A♭4 G4 | F3 A♭3 G3 | 低八度 |
| m.6 | E♭4 G4 F4 | E♭3 G3 F3 | 低八度 |
| m.7 | C4（D4 C4）**B3** C4 | C3（D3 C3）**B3** C3 | **B3 未降八度 → B3→C3 变成"七度下跳"的断裂** |
| m.8 | D4 E♭4 E4 | D3 E♭3 E3 | 低八度 |

即：整段被写成 C3 起（底本是 C4 起），而凡底本带高音撇号的音（`bes'`、`aes'`、`b`）又被照抄在**未降八度**的位置，造成两处不可能的跳进。

**八度到底谁对？三条独立证据都指向"底本（C4 起）对、交付件低了一个八度"：**
1. 印刷总谱（2017 版总谱 PDF p.86）该处大提琴声部**在进入处换次中音谱号**（`\bassToTenor`），旋律记在谱表**顶线及其上方**：次中音谱号第 4 线 = C4、第 5 线 = E4，可见 m.1 的 E♭4 就压在顶线上。若按交付件的 C3–B♭3，同样谱号下音符会掉到**谱表下方**，与总谱完全不符。
2. 同段中提琴（alto 谱号）伴奏为 C4 B♭3 G3 F3 A♭3 —— 主题若在 C3，会**低于自己的伴奏声部**，音乐上不成立。
3. 交付件里大管（C3 起的低音线）与大提琴（同样 C3 起）落在**同一个八度**，m.7 处大管还跳到 A♭4 而"旋律"留在 C3/B3 附近 —— 摘录内部自相矛盾。

**（c）连音线 ❌（编译警告来源）**

底本此段大提琴的连音为：`ees4.(` → m.2 `g16.[ f32 d8)]`（一条连音跨越两小节）；`c16.( d32)`、`ees4.(` → `bes'16. aes32 d,8)`、`d16.[( ees32])`、`aes16.( g32)`、`g16.( f32)`、`c8.( d32 c)`、`b16[( c])`、`d8( ees e …`。
交付件在 m.2、m.4 各**多写了一条底本没有的连音**：

```
m.2:  g16.(\p f32) d8) c16.( d32)     ← 底本只有 g16.[ f32 d8)] 这一条
m.4:  bf'16.(\p af32) d8) d16.( ef32) ← 底本只有 bes'16. aes32 d,8)
```

多出的 `(` 与后续 `)` 冲突，LilyPond 报：

```
S2-E2-…-m1-8.ly:53:7:  warning: already have slur
S2-E2-…-m1-8.ly:53:16: warning: cannot end slur
S2-E2-…-m1-8.ly:57:9:  warning: already have slur
S2-E2-…-m1-8.ly:57:19: warning: cannot end slur
```

⇒ **编译并非 0 warning**；且警告背后是真实的连音线错误，不只是排版噪音。

**（d）拍号/调号/速度 ✅**：3/8、c 小调、`Poco allegretto` 与底本 `TempoIII = {\tempo "Poco allegretto"}` 一致；数字 `4. = 100` 为增补（底本无数字）。

**（e）小节对应与摘录声明 ✅**：标题"mm.1–8（摘录：大管长音层 + 大提琴主题）"如实——确实只交付 2 个声部，未冒充全谱。

**（f）音域 ✅（形式合规）**：大管 B2–A♭4、大提琴 C3–B♭4，都落在给定范围内；但"在音域内"不等于"音高正确"，见 (b)。

2. **注释"m.27 起才以高八度承接"与底本不符（低）**：底本 Vn I 于 m.27 为 `e''4`（E5），而中提琴主题在 `e4`（E3）——相差**两个八度**，不是"高八度"。建议改为"以两个八度上方承接"或回避具体度数。
3. （旧 m1–18 版曾有"mm.19 起为 pp **低八度**重复"的错误表述，现版已改为"pp 重复，音型与 mm.11–18 相同"——**已修正**，记录备查。）

## 3. 勃拉姆斯圆号专项：确定结论与证据

### 3.1 那是完整总谱还是缩编？—— **完整管弦乐总谱（非改编/缩编）**

五条独立证据：

1. **工程自身声明**：`Common/version.ly` 与 `Common/Catalog.ly` 均写 `Brahms - Symphony nr 3 … encodage par J.F. Lucarelli`，目录编号 `005-BraSy3`（封底页脚 `005-BraSy3CondB`）。
2. **总谱 PDF 扉页**（`downloads/brahms-conductor.pdf`，**152 页**，`Creator: LilyPond 2.18.2`，`CreationDate 2017-06-21`）：标题 "Symphonie Nr 3 für großes Orchester in F dur Op.90"，副题 **"Conductor's Score"**；目录 **I–Allegro con brio p.5 / II–Andante p.54 / III–Poco allegretto p.84 / IV–Allegro p.96**。
3. **谱源行**：目录页明写 `Source : Johannes Brahms : Verlag und Eigenthum … N. SIMROCK in Berlin, 1884` → 依 1884 年 Simrock 初版总谱制谱。
4. **首乐章首页乐器表**（PDF p.5）与 IMSLP 上的全谱扫描（`downloads/brahms-imslp-p1.png`，Dover/Breitkopf 系，p.161）**乐器与排列完全一致**：Flöten I+II、Oboen I+II、Klarinetten (B♭) I+II、Fagotte I+II、**Kontrafagott**、**Hörner (C) I+II + (F) III+IV**、Trompeten (F) I+II、**Posaunen I+II+III**、Pauken、strings。缩编版不会保留这套编制与这种排版。
5. **第三乐章 staves 定义**（`BrahmsSYMPH3M3_Staves.ly`）：Fl I+II、Ob I+II、Kl I+II、Fag I+II、**Corno I+II**、Vn I/II、Va、Vc、Cb —— 小号/长号/定音鼓/低音大管在该乐章**不设谱表**（tacet），与总谱 PDF p.86 的第三乐章首页一致。

⇒ 结论：可authoritatively用于核对原谱的完整总谱；不是缩编。

### 3.2 mm.1–12 圆号是否真的休息？—— **是，而且休止远不止 12 小节**

- **源码**：`BrahmsSYMPH3M3_music-Corno_I_II.ly`
  ```lilypond
  \partial 8
  \tag #'hugeConductorScore { r8  R4. * 23 }
  …
  \mark \default      % Mark A - mesure 23   ← 注释的小节号差 1，见下
  \tag #'hugeConductorScore { R4. * 16  r4 }
  \leftDynamic c16.( \MPEspr d32)
  \mark \default      % Mark B - mesure 40   ← 同上
  ```
- **印刷总谱实证**：
  - p.86（第 III 乐章首页，**mm.1–11**）：Hr. (C) I+II 一整行**只有休止符**（弱起一个八分休止 + 5 个整小节休止；第 2 系统 6 个整小节休止）——见 `build-s2b/p086.png`、`build-s2b/c_fag_s1.png`（裁切含 Hr. 行）。
  - p.87（**mm.12–25，含排练记号 A**）：Hr. 行两个系统**全部是整小节休止，一个音符都没有**，包括 A 之后的三小节 —— 见 `build-s2b/p087.png`。
  ⇒ **圆号在 mm.1–25 之间确实一个音都不发**，与源码 `R4.*23` + `R4.*16` 完全吻合。

### 3.3 圆号首次进入在第几小节？—— **m.40 的最后一个八分（弱起），m.41（Mark B）起陈述主题**

我把印刷总谱的小节线坐标量出来了，以定小节号（不靠生产者注释）：

| 页码 / 系统 | 该系统起始小节（谱面左端印刷号） | 小节线 x 坐标（PDF pt） | 排练记号框 x | 推断 |
|---|---|---|---|---|
| p.87 第 2 系统 | **19** | 65.1 / 162.2 / 237.3 / 303.3 / 370.8 / **440.6** / 506.1 / 569.3 | **A ≈ 437–443（骑在 440.6 上）** | **Mark A = m.24** |
| p.89 第 1 系统 | **39** | 65.1 / 179.2 / **265.6** / 345.6 / 416.2 / 496.2 / 569.3 | **B ≈ 262（骑在 265.6 上）** | **Mark B = m.41** |

由此得到严格的小节账（弱起不计入小节号，与谱面印刷号一致）：

```
mm.1–23   圆号 R4.*23        全休止      （Mark A 在 m.24 起）
mm.24–39  圆号 R4.*16        全休止
m.40      圆号 r4 + c16.(d32)  → 首次发声 = m.40 第 3 个八分（弱起）
m.41      圆号开始陈述主题     （Mark B，A♭ 中段开始）
```

**对生产者说法的裁定**：
- "圆号（Corno I/II）在 mm.1–23 为全休止" —— **正确** ✅
- "源码 `\partial 8 r8 R4. * 23`" —— **正确** ✅
- "Mark A 在 m.23" —— **差 1 小节，应为 m.24** ❌（同一错误也出现于"Mark B 在 m.40"，应为 m.41；系编码者把弱起算作第 1 小节所致）
- "长音层实为大管（m.1 起）+ 单簧管（m.13 起）" —— **正确** ✅

### 3.4 长音层到底是谁？—— 大管自 m.1，单簧管自 m.13

- **大管 I/II**：源码 m.1 起 `c4 \p r8 | f4 r8 | c4 r8 | f4 r8 | b,4 r8 | c4 r8 | aes'4 r8 | g8 c bes …`（四分音符 + 八分休止的律动低音）。
- **单簧管 I/II**：源码 `\partial 8 r8 R4. * 12  r16` 然后 `a8( a a16 …` → **mm.1–12 全休止，m.13 末的十六分弱起进入**。印刷总谱印证：p.86（mm.1–11）Kl. 行无音符；p.87 第 1 系统（自 m.12 起）第 2 小节起 Kl. 已有音符（m.13）✅。
- **圆号**：全 A 段沉默（见 3.2/3.3）。

### 3.5 对文章 `techniques/sound/planes-of-tone-layering.md` 案例二的影响

- 若案例二称"mm.1–12（或开头若干小节）圆号与木管形成长音共鸣"，**不成立**：圆号此时不在场，而承担持续/共鸣层的是大管（m.1 起）、单簧管（m.13 起）。
- 若仍要保留"圆号"这一环，正确落点应是 **A♭ 中段（m.41 起，Mark B）**——那里圆号才首次进入并陈述主题；引用时应写明"圆号首次进入在 m.40 末的弱起 / m.41 起"。
