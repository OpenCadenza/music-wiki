### 3.3 移调（`\transposition` 语义）—— 记谱音与实音都正确

- `\transposition a`：记谱 c' 发声 a（低小三度）→ A 调单簧管 ✔
- `\transposition f`：记谱 c' 发声 f（低纯五度）→ F 调圆号 ✔

实测（编译后 MIDI）：单簧管记谱 g''（G5, midi 79）→ **E5 (76)**；圆号记谱 fs'（F#4, 66）→ **B3 (59)**。与 XML 的 `transpose chromatic = -3 / -7` 完全吻合。

**另外独立验证了"`\transposition` 不影响谱面"这一关键前提**：把两处 `\transposition a/f` 改成 `\transposition c` 后重编译，两页 PDF 渲染出来**像素完全一致**（`tmp/pdfpng.py` 比对，sha1 相同）。因此：

- 谱面印出的就是源码里的音高（生产者按"演奏者所见记谱音"书写 → 正确）；
- MIDI 的实音 = 记谱音 + 移调；
- 由于 `.ly` 的移调量与 XML 完全相同（-3 / -7），而 MIDI 实音又与 XML 实音全同，可反推 **`.ly` 的记谱音 = XML 的记谱音**（逐音成立，不是"凑巧抵消"）。

**判定：记谱音与实音两条都正确，谱面调号（1 升 / 5 升）也正确。**

### 3.4 两处非缺陷的细微差异（仅记录）

1. **断奏被 MIDI 缩短**：`.ly` 的 `-.` 在 MIDI 里把八分 0.5→0.25、十六分 0.25→0.125，属预期行为，不影响谱面。
2. **大管第 5 小节末音 `fs'8` 的 MIDI 时值为 0.385 拍（应为 0.5）**：已用最小测试文件复现，是 LilyPond 的装饰音取时机制在 MIDI 上的副作用，**谱面时值正确**（32 分音符以外无任何变化），不影响交付。
3. 装饰音：五声部装饰音数量与音高全部对上（长笛/双簧管各 2 组共 4 个音；单簧管/大管各 4 组共 8 个）。大管的装饰音在 XML 上**不带**连音线，`.ly` 也**没写**连音线（长笛/双簧管/单簧管带，`.ly` 也带）—— 处理正确。

## 4. ★ 小节 8（XML 7）的 5/4 —— **交付件判断错误，应照 XML 保留 5/4**

### 4.1 交付件做了什么

`.ly` 与 `核对记录.md` §4 把一个 XML 标为 **5/4** 的小节（XML 小节 7 = 印刷谱第 7 小节）当作 **OMR 多读一拍休止**，按 4/4 归一：长笛/双簧管/单簧管/大管把开头休止各减 1 拍，圆号把句尾休止减 1 拍。

### 4.2 我独立取得的决定性证据：谱面本身就是 5/4

**校勘版谱面直接给出了拍号变化。** M. L. Spence《Carl Nielsen's Quintet for Winds, Op. 43: A Critical Edition》（UNT 1995，据尼尔森手稿校订；论文明确写"manuscript score is in agreement with the published score"）的谱面（PDF 第 106 页 = 印刷页码 94）第一行从**第 6 小节**起，逐字可读：

- 行首小节号 **`6`**（无拍号 ⇒ 承接前面的 4/4）；
- 第一道小节线处：**`5/4`** 拍号（`5` 在上、`4` 在下），五个声部同时印出；进入该小节后大管/长笛的记谱是「二分休止 + 八分休止 + 十六分音型」；
- 第二道小节线处：**`4/4`** 拍号（数字形式，非 common 记号）。

放大裁切：`tmp/sys1_full.png`（整行 480 dpi）、`tmp/sig54.png`（5/4 竖切）、`tmp/sig44.png`（4/4 竖切）。

这与 XML 完全一致：`m.7 → <time>5/4</time>`、`m.8 → <time symbol="common">4/4</time>`；连该小节的休止形态也对得上（生产者在 `核对记录.md` §4 表格里记录的"二分休止 + 八分休止 + …"正是谱面原样）。

### 4.3 其它证据的一致性

- **五个声部该小节总时值都是 120/24 = 5 拍**，其余小节都是 96/24 = 4 拍 —— 与"谱面确为 5 拍"相容。
- "Kvnintet"（75 611 字节，丹麦语声部名，147 小节 = 仅第一乐章）同样在 m.7 标 5/4、m.8 回 4/4；我逐音比对了它与 op43 的 m.0–11：**音高/时值/onset 全部相同**，差异只在连音线编号、一处时值（大管 m.5 末音 八分 vs 十六分）和头部元数据。**所以它确实不是独立旁证**（生产者这一点判断正确），但它与"谱面为 5/4"并不矛盾。
- 生产者"该小节正好是分页点"的论证：`<words>Page 4</words>` 确实落在 m.7，`<print new-page>` 在 m.9（即 m.1–8 为第 4 页）。这个观察是真的，但**不能推出 5/4 是伪的** —— 谱面既然写着 5/4，OMR 只是照录。

### 4.4 交付件的实际后果

归一之后，长笛/双簧管/单簧管/大管在该小节的音**整体提前 1 拍**（我实测：这四声部该小节及之后所有音的 onset 相对 XML 全部 −1.000 拍，误差 0.000）。也就是说谱面上这四件乐器的进入位置与尼尔森写的**不一样**；只有圆号因为多余拍在句尾而位置未变。这不是"排版口味"，是**实质性的节拍错误**。

### 4.5 结论与修法

**判定：应照 XML 保留 5/4；当前的"归一为 4/4"必须撤销。**

修法（三处）：

```lilypond
global = { \time 4/4 \partial 4 \tempo "Allegro ben moderato" 4 = 100 ... }

% 各声部：XML 小节 7 之前插入 \time 5/4，小节 8 之前插入 \time 4/4
% 并把休止还原为 XML 原样：
%   长笛/双簧管   r2 r8  （现为 r4 r8）
%   单簧管        r2 r4  （现为 r4 r4）
%   大管          r2     （现为 r4）
%   圆号          句尾 r2（现为 r4）
```

具体到五个声部（`.ly` 现文 → 应改为）：

| 声部 | 现文（小节 7） | 应改为 |
|---|---|---|
| flute | `r4 r8\mp c'''16…` | `\time 5/4 r2 r8\mp c'''16…`，小节 8 前加 `\time 4/4` |
| oboe | `r4 r8 \pp a''16…` | `\time 5/4 r2 r8 \pp a''16…`，小节 8 前加 `\time 4/4` |
| clarinet | `r4 r4 g'16…` | `\time 5/4 r2 r4 g'16…`，小节 8 前加 `\time 4/4` |
| horn | `…b'4 r4 \|` | `\time 5/4 …b'4 r2 \|`，小节 8 前加 `\time 4/4`（圆号本小节内音不动） |
| bassoon | `r4 e'2.~( \|` | `\time 5/4 r2 e'2.~( \|`，小节 8 前加 `\time 4/4` |

拍号印在各声部：谱面正是五个声部同时印 5/4 与 4/4，所以直接写在每个声部里即可，不需要 `\set Timing` 之类的隐藏处理。改完 barcheck（`\|`）会随新拍号自动校验小节时值，正好可以当作自制检查。

## 5. 弱起与小节编号

### 5.1 `\partial 4` 与 XML 一致

XML 小节 0：四个声部为 1 个四分休止（duration 24/24 = 1 拍），大管为 `b8 gs8`（12+12 = 24 = 1 拍）。**弱起 = 1 拍**，`\partial 4` 正确（该小节总时值 1.000 拍，与 `\partial 4` 相符）。

### 5.2 谱面编号：印本"弱起不编号、第一个完整小节 = 1"

校勘版谱面第一页可读到：弱起小节**没有任何编号**，第一个完整小节前印 **`1`**，第二行开头印 **`3`**（即第一行 = 弱起 + 1、2 小节）。也就是说 **印刷谱的 m.N = XML 的 m.N**，弱起在计数之外。

LilyPond 的产物与此**部分吻合**：`.ly` 打印出的号是 `(1)`（弱起）+ `1, 2, 3, …, 11`（XML 1–11）。**完整小节号与谱面一致** ✔；但弱起上多出一个 `(1)`，那是 LilyPond 对 `\partial` 的固定显示，印本上没有，可能让人以为"弱起 = 第 1 小节、下一小节也是第 1 小节"。

### 5.3 因此"mm.1–12 含弱起"会误导（需改 location）

本谱例实际内容 = **弱起 + 印刷谱 mm.1–11**，共 12 个 `<measure>`；**不含印刷谱第 12 小节**。若写作"mm.1–12"，读者按谱面号去找第 12 小节会找到谱例之外。生产者 `核对记录.md` §2 末条其实已经意识到这点，但成品 `.ly` 头部注释（第 9 行"本谱例 = 印刷谱第 1–12 小节，即文章所称 mm.1–12"）仍是错的。

**建议的 location 写法（任选其一）**：

- 若保持现有内容：`mm.1–11（含 1 拍弱起，谱例共 12 小节）`
- 若必须真的覆盖"前 12 小节"：把尾巴延到 XML 小节 12，再写 `mm.1–12`（谱例变成 13 个 `<measure>`），并在 location 注明"含弱起"。

### 5.4 附带发现：小节号的"断点重复"与"幽灵号"

`.ly` 里有

```lilypond

\override Score.BarNumber.break-visibility = #all-visible
```

第二行覆盖了 LilyPond 的默认值 `end-of-line-invisible`，结果是**每行行末都会印出下一行第一个小节的号，并且作品结束后还会多印一个号**。实测该 PDF 页 1 的三行行末分别是 `4`、`6`、`8`，而下一行行首也是 `4`、`6`、`8`；页 2 行末 `10`，下一行行首也是 `10`；最后一行的行末是 **`12`**，但全谱最后一小节是 **11**，并没有第 12 小节。

这不是致命的（号在行末、且与行首重复，多数读者会认为是行号），但确实会让"谱例到第 11 还是第 12 小节"更含混，和 §5.3 的问题叠加。

**建议：删掉 `\override Score.BarNumber.break-visibility = #all-visible` 一行**（保留 `barNumberVisibility = #all-bar-numbers-visible` 即可让每小节都出号），重复号与幽灵号即消失。

## 8. 其它发现（不构成回填阻塞，供参考）

1. **单簧管 m.4 的 `f''` 在 XML 里带一个多余的 `natural`**（G 大调本已 f 自然，属提示性还原号）。`.ly` 不写，谱面干净；音高相同。属排版差异，非错误。
2. **大管 m.5 末音的时值在两份 OMR 出口之间有分歧**：op43 = 八分（0.5）、Kvnintet = 十六分（0.25）。`.ly` 取八分，**这也是唯一能让该小节凑满 4 拍的读法**（取十六分会缺半拍）。生产者的选择正确。
3. **圆号第 7 小节第 3 个音是已知的谱面异文**：Spence 论文例 2 专门列了"horn part, mvt. I, m. 7, third note"在尼尔森手稿与 Hansen 分谱之间不一致。`.ly` 照 XML 录入，不算缺陷；若文章要专门讲这一小节，可加脚注。
4. `\textMark "calando"` 只在长笛声部标一次：XML 在长笛/双簧管/单簧管三处都写了。总谱上同一次渐慢只标一处是通行做法，**可接受**；如果想严格照 XML，可以三处都标（会显得重复）。
5. 尾部延音线被删除（长笛 m.11 的 `b''2` 原与下一小节相连）属必要处理（否则 `unterminated tie`），已在 `核对记录.md` §6 说明。可接受。
