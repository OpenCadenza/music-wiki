## 转换路径
1. `extract_mm.py` 从原件抽出纯数字编号的 mm.1–8（丢弃 `<harmony>`/`<print>`/`<barline>`）→ `x-op109-3-mm1-8.xml`。
   *注意*：DCML 把主题后半（印刷 mm.9–16）导出为 `implicit="yes"` 的 `X1…X8`，抽取时必须只认纯数字小节号，否则 X1–X8 会被误当 1–8。
2. `python .../musicxml2ly.py --absolute -o draft-op109-3.ly x-op109-3-mm1-8.xml` 得到机器草稿。
   草稿可用于音高/时值核对，但**不能直接交付**：两张谱表被当成两个 part、声部小节线错位（voice 2 出现 `s1`/`s2.` 错配）、音名为荷兰语（`gis`/`dis`）、并生成空 lyrics 占位块。
3. 依草稿与 XML 数据手工重排为 `PianoStaff` 双谱表、绝对音高（`\language "english"`），逐条对齐倚音、连音线、重音与力度；每小节末写 `|` 显式小节线。

## 核对结论

### 小节对齐
- 无弱起；DCML 的 m.1 即印刷 m.1。调号 fifths=4、3/4，与 kern `*k[f#c#g#d#]`、`*M3/4` 一致。
- DCML 在 m.8 之后转入 implicit 的 X1–X8；kern 在 `=9` 处标 `:|!|:`（反复记号）。两源都表明 **mm.1–8 是自成一段的第一段**，与任务要求的「变奏主题 mm.1–8」吻合。本谱例按摘录惯例在 m.8 收普通小节线（不复现反复记号）。

### 音高与时值
- **DCML vs kern**：mm.1–8 逐小节比对（含和弦音）**8/8 完全一致**。
- **编译 MIDI vs XML**：MIDI 83 音；逐小节音高多重集比对，m.1–8 主体音全部命中，唯一差异是 m.5 左手 G#2 的同音并置被 LilyPond MIDI 归并掉 1 个（见下「差异 1」）。
- **音域自查**：B1–B4（MIDI 35–71），落在 A0–C8 内。
- 比对脚本：`compare_midi_xml.py`（用自写的最小 MIDI 解析器按 3/4 小节切分，再与 XML 逐小节比多重集）。

### 与两源之间的差异（逐条处理，均已说明）
1. **m.5 左手 G#2**：DCML（v1 四分 240 + v2 二分 480）与 kern（`4GG#` + `(2GG#`）都同时记两个同音 G#2。谱例如实按双声部写出（四分为 v1、二分为 v2），因此 MIDI 中该音重合、由 LilyPond 归并。
2. **m.5–6 右手连音线**：DCML 只给一条从 m.5 第一枚倚音横跨到 m.6 末音 A3 的长连线；kern 分作两条（m.5 `b′→f♯″16`、m.6 `d♯′→a′`）。谱例取 kern 的分写：音高与时值不变，只影响连线起止；跨「临时声部」的单条长线在 LilyPond 中无法整洁表达。
3. **m.7 右手连线起点**：DCML 起于 E4（`slur start #1` 在 m.7 E4），kern 起于 G♯3。依主源 DCML。
4. **力度**：DCML 该段**无任何力度标记**（整份文件只有 21 个小节带 `dynamics`，最早出现在 m.14）；kern 在 m.1 有一条斜体演奏提示、在 m.8 标 `p`。谱例只取可核的 **`p`（m.8）**。m.1 那条提示在本地 kern 副本中被安全扫描脱敏为占位符，无法据以复原原文，故未写入——如需该字样，应以 kernScores 原站为准另行核校。
5. **运音**：DCML m.7 E4 记 accent；kern 记 tenuto + accent。依 DCML 作 `->`。
6. **踏板**：kern m.5 有踏板起止；DCML mm.1–8 无踏板记号。谱例不写踏板（避免单源引入）。
7. **谱号**：m.8 右手换低音谱号（DCML `clef=F4`、kern `*clefF4`），照写。
8. **速度**：乐章标题 *Andante molto cantabile ed espressivo*；节拍机 `♩ = 84` 取自 kern `*MM84`（DCML 导出无 `metronome` 元素）。

### 编译与规格自查
- LilyPond 2.26.0：**0 error / 0 warning**（含默认 bar check，逐小节 `|` 均通过）。
- `\version "2.26.0"` + `\language "english"`；title 含作品号（Op. 109）与乐章（III. Andante molto cantabile ed espressivo，Tema mm. 1–8）。
- 钢琴双谱表 `PianoStaff`；MIDI `midiInstrument = "acoustic grand"`，实测 program change = 0（GM 0），双谱表各一轨。
- 版面：1 页 2 系统（mm.1–4 / mm.5–8）。
