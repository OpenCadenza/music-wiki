## 2. 八度基准（先校准，再编码）

kern 的绝对八度约定若读错就是整段高低一个八度——这是前几轮返修的主因（SCR-003 / SCR-034）。所以本轮先拿**已入正文且经独立核验**的同语料片段做校准：

- 参照：`local/workbench/scores/score-s2/S2-D2-beethoven-op131-m6-11.ly`（正文 `beethoven-op131-i-mm6-11`，核验一致）
- 参照底本：同一 `quartet14-1.krn` 的 mm.6–11
- 逐项比对：

| kern | 参照 .ly | 结论 |
| --- | --- | --- |
| `a`（m.6 首音） | `a'` = A4 | kern `c` = 中央 C（标准） |
| `ee`（m.8） | `e''` = E5 | 两个小写 = 高一个八度 |
| `dd#`（m.8） | `ds''` = D♯5 | `#` = 升号 |
| `cc#`（m.5） | `cs''` = C♯5 | 同上 |
| `e#`（m.6–7） | `es'` / `es''` | english 下 `es` = E**♯**（不是 E♭，E♭ 写 `ef`）⇒ 与 kern 一致，无冲突 |

结论：**该语料 kern 八度 = 标准（`c`=C4、`cc`=C5、`C`=C3）**，可放心取绝对音高。本片段据此编码。
