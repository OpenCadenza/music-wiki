## 2. 取段：为什么是 mm.1–16（而不是 1–35 或 16–35）

底本 mm.1–35 的 14 个 part **全都会发声**（只是进入点不同），做成 14 谱表 × 35 小节在网页谱里会到 5–6 页、且每小节都是密集弦乐 tremolo，可读性差。本片段取 **mm.1–16** 的理由：

1. **mm.1–16 是"逐级叠加入场"的完整过程**：从 m.1 只有弦乐 tremolo + 圆号，到 m.16 全乐队（含小号、定音鼓）第一次同时发声。所有进入点都落在这一段里（见 §3）。
2. m.16 正好是"全奏爆发"的**起点**（本片段终止于该小节的强拍），把"叠加入场 → tutti"的因果交代完整。
3. 若取 mm.16–35，则丢掉了"空洞开场"（空五度、无三音）这一半——而正文的论点恰恰建立在"从极稀薄到极饱和"的对比上。

**谱表取舍（14 → 12）**：省略 **Corno 3,4（in B♭ basso）** 与重复声部 **Violoncello e Contrabasso**（该 part 与 Vc/Cb 重复）。前者在 mm.1–14 全休止、**m.15 才进入**——这一进场在本片段谱面上看不到，仅在此登记：

> Corno 3,4（B♭ basso）：底本 m.15 起进入（m.15 两音、m.16 六音）。若需要在谱面上体现，加一行即可（本目录 `.ly` 里加 `corniBassi` 并有已备好的解析输出）。

## 3. 逐声部实际入场（按底本解析，mm.1–16；**这就是"谱面事实"，不是文章预期**）

| 小节 | 新进入的声部（底本记录） |
| --- | --- |
| **m.1** | Violino II、Violoncello（+ Corni 1,2 已在 m.1 发声）、Contrabasso 的 `E3`/`A2` 低音也在 m.4 前有零散记号 |
| **m.2** | **Violino I**（一个 32 分音符 E5 起句） |
| **m.4** | **Viola**、**Contrabasso**（`E3` 起） |
| **m.5** | **Clarinetti 1,2 in B♭**（长音 B4，实音 A4） |
| **m.9** | **Oboe 1,2**（长音 E5） |
| **m.11** | **Flauti 1,2**（长音 A5） |
| **m.14** | **Fagotto 1,2** |
| **m.15** | Corno 3,4（本片段未列谱表，见 §2） |
| **m.16** | **Trombe 1,2 in D**、**Timpani**；全乐队第一次同时发声（tutti 起点） |

- 弦乐 tremolo 的**实际音高**（解析 + MIDI 实测）：Vn II = E4/A3、Va = E4/A3、Vc = E3/A2、Cb = E3/A2 —— 即 **A–E 空五度，无三音**；圆号实音 E4/A3 也叠在这个五度上。
- 直到 **m.16** 各声部才出现 D（主音）与完整的 D 小调形态（例：长笛 m.16 的 `a'''4~ a'''8.. d'''32`，实音 A6 + D6）。

**→ 正文/贝尔金描述的两条需要核对**（本助手只报数据，判断留给学者/主控）：
1. 正文写"混沌起步（mm.1–15）：只有圆号长音震音与第一、第二小提琴……"——底本里 **m.5 起单簧管、m.9 起双簧管、m.11 起长笛已在发声**，所以"只有圆号与第一、第二小提琴"不成立；正确的说法是"mm.1–4 只有弦乐（Vn II/Vc 的 A–E tremolo，Vn I 从 m.2 进入）与圆号；m.5–15 木管各组依次加入长音"。
2. 正文"贝尔金指出的入场次序：低音弦乐下坠，继而中提琴，随后木管各组逐次进入"——与本片段吻合（Vc/Cb m.1–4、Va m.4、Cl m.5、Ob m.9、Fl m.11、Fg m.14）✔。

## 4. 移调乐器怎么写的（写实音，便于阅读且有和声自证）

| 声部 | 底本调 | 写谱→实音 | 依据 |
| --- | --- | --- | --- |
| Clarinetti 1,2 | in B♭ | 下大二度（写 `b'`=B4 → 实 A4） | 标准 B♭ 单簧管 |
| Corni 1,2 | in D | **下小七度**（写 `d''`=D5 → 实 E4；写 `g'`=G4 → 实 A3） | ①五度对照：实音 E4/A3 恰与弦乐 A–E 空五度叠合；②m.16 处写 `c'''`=C6 → 实 D5＝主音（若不这样移，会得到 D6，圆号不可能且和声不是主音） |
| Trombe 1,2 | in D | 同上，下小七度（写 `c''`=C5 → 实 D4＝主音） | 与圆号同一套 C 记谱惯例；m.16 落在主音上 |
| Timpani | in D, A | 不移调（写 `d`=D3） | 定音鼓谱即实音 |
| 弦乐/木管其余 | — | 不移调（MuseData 已是实音） | — |

- 交付件**不写** `\transposition`（谱面与 MIDI 都是实音），故纸面直接读得出"空五度 A–E"。这一点与 Op.92 片段（SCR-040）的处理一致，已在 `.ly` 头注释与本记录说明。

## 5. 记谱简化（逐条登记）

1. **弦乐 tremolo**：底本用 MuseData 的缩写记法（每音 `divs=4`、`Q:24`，即 **1/6 四分音符**；一组 12 音＝一小节），且带 `[[ ]]` 等括号标记。本片段按**实际时值**写成 `\tuplet 3/2 { 音16 ×12 }`（每小节一组、每声部一组），节奏与底本完全一致，但**印刷谱原为 tremolo 记号**（反复横线），属"记谱从简"，verifier 若要求可改回 `\repeat tremolo` 或 `:32` 写法。
2. **跨小节连音线**：按 MuseData 的 `-` 连音标记，在**同一小节内**与**跨小节**都保留（每声部整段渲染后拼小节，故连音线正确）；末小节（m.16）通向 m.17 的连音线**不写**悬空 `~`。
3. **整小节休止**：写成 `R2`（2/4 的全休止记号）。
4. **底本某声部整小节只有几个音**（MuseData 不补填充休止，例如小号 m.16 的第二声部只有一个 32 分音符）：本片段**自动补足该小节的休止**到 2 拍，已由 LilyPond 的小节校验确认（编译 0 条 barcheck 警告）。
5. **力度**：底本 `**dynam` 记录只在 `P C34:`/`*pp` 之类的排版行里出现，未在本片段内逐点转译（本片段除 `\tempo` 外不写力度记号）；如需 pp/cresc. 可下一轮按底本 `*` 行补。
6. **纸张/字号**：`a4landscape` + `#(set-global-staff-size 13)`，12 谱表 × 16 小节排成 **2 页**；这是版面决定，不影响音高/时值。
