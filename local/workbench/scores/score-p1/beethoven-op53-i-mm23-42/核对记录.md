## 3. m.42 的 12 分音符（三连八分）

底本 `*Xtuplet`，右手 12 个 `12` 时值 token（= 1/12 全音符 = 三连八分），按 4 组 `\tuplet 3/2` 排版：

| 组 | 底本 token（印刷音高） | 本交付 |
| --- | --- | --- |
| 1 | `12G#<'> 12e'>L`（同记录 = **和弦 G♯3+E4**）、`12f#'`、`12g#'` | `\tuplet 3/2 { <gs e'>8 fs'8 gs'8 }` |
| 2 | `12a'`、`12b'`、`12cc#'` | `\tuplet 3/2 { a'8 b'8 cs''8 }` |
| 3 | `12dd'`、`12dd#'`、`12ee'` | `\tuplet 3/2 { d''8 ds''8 e''8 }` |
| 4 | `12ee#'`、`12ff#'`、`12ff##'` | `\tuplet 3/2 { es''8 fs''8 fss''8 }` |

- 首组第一个音是**和弦 G♯3+E4**（低音谱表外的 G♯3，与左手 E2+E3 合成 E 大调四音叠置 E2-E3-G♯3-E4）；kern 把两个 token 放在同一记录，本交付据此写成和弦，**未提八度**。
- `fs''`×2 + `fss''` 是 F♯5 → F♯♯5 的半音上行（`四源`均如此），不是转写重复。
- 左手 m.42 = `4EE 4E` → `<e, e>4`（E2+E3），其后 `4r` + `2r`。
