## 0. 核验方法（可重跑）

1. **底本解析**：按 `score: part N of 14` 切 part；每 part 读 `$` 行的 `Q`（**本文件 Q 不统一**：Part 5/6/7/8 = `Q:8`，其余 = `Q:24`），全部换算到 1/24 拍；识别三种记录形态：**行首一个空格的音符 = 上一音的同发响点和弦音**（不推进时间）、`back N` = 换声部、`g` 前缀（如 `gBf4`）= 倚音（占 4 divisions，不推进主拍）。
2. **交付件解析**：按 `staff = { … }` 取块，`\\` 分声部、`|` 分小节，解析和弦 `<…>`、`\tuplet 3/2` 缩放、附点/复附点、休止。
3. **两轮逐音比对**（35 小节 × 13 谱表 = 455 个「谱表·小节」单元）：
   - 第一轮：每小节的**音高多重集**（含和弦全部音）；
   - 第二轮：每小节的**发音点 + 时值 + 和弦形态**（float 比对容差 0.01 division）。
4. **独立旁证**：① 交付 `.mid` 按 2/4 展开成「小节 → 音高集合」与 `.ly` 文本解析互证；② MXL 逐 part 的 `<transpose>` 与写谱音高；③ 实编译日志。
5. 结果：**md2 侧 1,876 个发响音 vs 交付件 1,873 个**；偏差仅集中在 3 个倚音（见 §3-D2/D3）。除此之外，455 个单元的音高多重集与发音点-时值表**全等**。

### 2.3 开场音集与 D 主音

- **m.1 全声部并集 = {A2, E3, A3, E4}（MIDI 45/52/57/64，各 12 次）**：空五度，**无三音（无 F/F♯）、无导音（无 C♯）**。圆号实音 A3/E4 与弦乐 A–E 完全叠合，**成立**。
- **m.1–4 并集 = {A2, E2, E3, A3, E4, A4, E5}**：仍只有 A、E 两音级（m.2 起 Vn I 加 E5/A4，m.4 Cb 加 E2）。
- **D 主音首次出现：m.15**，不是记录所写的 m.16。依据（三源一致）：Fagotto m.15 = A1(8 分) → **D2**(附点二分)；Corno 3,4 m.15 = **D3/D4**。m.15 并集 = {D2, A2, D3, A3, D4, A4, A5, A6}。
- **m.16 全奏并集 = {D2, D3, D4, A2, A3, A4, D5, D6, A5, A6}**：仍是 **D–A 空五度，没有三音**。
- **三音 F 首次出现：m.17**（Fl F6/F5、Vn I F5、Hn/Ef→F 等），调性至此才「完整」。

→ 结论：m.1 的「A–E 空五度」表述**正确**；「主音 D 到 m.16 才出现 / m.16 即完整 D 小调形态」**不正确**（D 早一小节、三音晚一小节）。正文若沿用该句需改。
