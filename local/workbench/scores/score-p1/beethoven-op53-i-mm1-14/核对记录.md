## 2. 底本读法的两条坑（R201 阻断的真实原因）

原阻断报告把三处小节累加成 4.5 拍。查证后是三条读法错误，**不是底本缺陷**：

| # | 误读 | 正确读法 | 影响 |
| --- | --- | --- | --- |
| 1 | 把 `8qccc#` 当八分音符（+0.5 拍） | kern 的 **`q` = 倚音（grace）**，时值 **0**，不推进时间 | m.4 / m.8 / m.9 |
| 2 | 把 `([4ddd)` 当附点四分（1.5 拍） | 附点会写成 `4.ddd`；此处为 **四分（1.0）** | m.4 / m.8 |
| 3 | 把 `8GG] (8GL]` 当两个八分相加（1.0） | 同一 spine 内**空格分隔的多个 token = 同时发声的和弦**，是**一个八分（0.5）**；`[`/`]` 是**连音线**不是符杠 | m.11 左手 |

统一口径（本次自写解析器采用，`§5.2` 有可复现说明）：
**数据记录的时间推进量 = 各 spine 当前"剩余发声时值"的最小值**；`"."` = 延续（不提供新时值）；`q` = 0；同 spine 多 token = 和弦（取最短时值，不累加）；`12`/`24` 等 = 1/n 全音符（m.42 用）。

## 3. 逐小节依据（kern 原文 → 本交付）

**音区**：kern `c` = C4（中音 C）为八度基准，`C` = C3、`CC` = C2、`ccc` = C6。此基准经三条独立证据锁定：① 底本 mm.1–3 右手用**低音谱号**（`*clefF4`）书写，说明其 C3+E3 落在低音谱表内；② m.4 花彩顶点 `ccc`/`ddd` = C6/D6，与"高音谱号 + 加线"的图像相符；③ **源 B 实测 m.1 右手 = MIDI 48/52（C3/E3）、左手 = 36/43（C2/G2）**，与 kern 逐音一致。
