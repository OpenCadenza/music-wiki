## 2. 底本读法的两条坑（R201 阻断的真实原因）

原阻断报告把三处小节累加成 4.5 拍。查证后是三条读法错误，**不是底本缺陷**：

| # | 误读 | 正确读法 | 影响 |
| --- | --- | --- | --- |
| 1 | 把 `8qccc#` 当八分音符（+0.5 拍） | kern 的 **`q` = 倚音（grace）**，时值 **0**，不推进时间 | m.4 / m.8 / m.9 |
| 2 | 把 `([4ddd)` 当附点四分（1.5 拍） | 附点会写成 `4.ddd`；此处为 **四分（1.0）** | m.4 / m.8 |
| 3 | 把 `8GG] (8GL]` 当两个八分相加（1.0） | 同一 spine 内**空格分隔的多个 token = 同时发声的和弦**，是**一个八分（0.5）**；`[`/`]` 是**连音线**不是符杠 | m.11 左手 |

统一口径（本次自写解析器采用，`§5.2` 有可复现说明）：
**数据记录的时间推进量 = 各 spine 当前"剩余发声时值"的最小值**；`"."` = 延续（不提供新时值）；`q` = 0；同 spine 多 token = 和弦（取最短时值，不累加）；`12`/`24` 等 = 1/n 全音符（m.42 用）。

## 3. 逐小节依据（kern 原文 → 本交付）

**音区**：kern `c` = C4（中音 C）为八度基准，`C` = C3、`CC` = C2、`ccc` = C6。此基准经三条独立证据锁定：① 底本 mm.1–3 右手用**低音谱号**（`*clefF4`）书写，说明其 C3+E3 落在低音谱表内；② m.4 花彩顶点 `ccc`/`ddd` = C6/D6，与"高音谱号 + 加线"的图像相符；③ **源 B 实测 m.1 右手 = MIDI 48/52（C3/E3）、左手 = 36/43（C2/G2）**，与 kern 逐音一致。

| 小节 | 左手（lower） | 右手（upper） | 和声 / 结构 |
| --- | --- | --- | --- |
| 1 | `c,8` 单音 C2，其后 C2+G2 ×7 | 八分休止 + C3+E3 ×7 | 主和弦（**首拍右手休止、左手单音起拍**） |
| 2 | C2+G2 ×6 → C2+A2 ×2 | C3+E3 ×6 → D3+F♯3 ×2 | 末拍换属向邻音 |
| 3 | B1+G2 ×8（低音 C2→B1 半音下行） | `4.` D3+G3 → `16` B3 `16` A3 → `8` G3 → `8r` `4r` | G/B（V⁶）收束 |
| 4 | B1+G2 ×8 | 倚音 C♯6 → D6 四分（**连音**入十六分）→ C6-B♭5-A5 → G5 四分 → 四分休止 | 花彩；底本在此换高音谱号 |
| 5 | B♭1+F2 ×8（低音 B1→B♭1） | B♭2+D3 ×8 | **B♭ 大调（对 m.1 下方大二度模进）**，力度 pp |
| 6 | B♭1+F2 ×6 → B♭1+G2 ×2 | B♭2+D3 ×6 → C3+E3 ×2 | — |
| 7 | A1+F2 ×8（低音 A♭…→A1） | `4.` C3+F3 → `16` A3 `16` G3 → `8` F3 → `8r` `4r` | F/A（IV⁶）；底本自 m.7 起渐强 |
| 8 | A♭1+F2 ×8 | 倚音 B♮5 → C6 四分（连音）→ B♭5-A♭5-G5 → F5 四分 → 四分休止 | 与 m.4 同型，下移大二度；底本在此换高音谱号 |
| 9 | G1+F2 ×6 → A♭1+F2 ×2（底本 `<` 渐强延续） | 倚音 E6 → F6 附点二分 → `16` F6-E♭6-D6-C6 | 高点；G7 外壳 |
| 10 | G1+F2 与 A♭1+F2 逐拍交替 | 16 个十六分：B♭5-C6-D6-E♭6-F6-E♭6-D6-C6 ×2 | 十六分音型二分句 |
| 11 | G1+F2 四分 → **G2+G3 二分（连音入八分）** → A3 `16` B3 `16` | 16 个十六分：B♭5…下行至 B4 | 低音 G/A♭ 摇摆 + 半音靠近 C |
| 12 | C4（承接 m.11 的 A3-B3-C4 上行）→ G2+G3 → E♭2+E♭3 → C2+C3，每拍后 8 分休止 | C5、G4、E♭4、C4（与左手同步） | 八分柱式和弦下行，底本 `>` 渐弱 |
| 13 | G1+G2 全音符 + 延长号 | G3 全音符 + 延长号 | 三个八度的 G，p |
| 14 | C2+C3 八分起句 → C3-G3 十六分 ×14 | E4-C4 十六分 ×16（**首音底本带 courtesy natural，本交付写 `e'!` 强制还原**，以还原 m.12 的 E♭） | 新句 pp |

### 5.1 三源逐小节音高多重集比对（34 小节 × 2 谱表）

| 对比 | mm.1–14 差异小节 | mm.23–42 差异小节 |

| **源 B（MuseScore/PDMX）↔ 本交付** | **0 / 14** | **0 / 20** |
| 源 A（MuseScore/PDMX）↔ 本交付 | 1 / 14（m.12） | 7 / 20（m.23–26、m.28、m.32、m.39） |

- **A 与 kern/B 的分歧（登记为源间冲突，本交付取 kern+B）**：
  - m.12 末拍左手和弦：kern/B/本交付 = C2+C3；**A = A1**+C3。
  - m.23–26：A 的第二半小节左手保持 B 大调琶音（D♯3+F♯3），kern/B 换成 B2–E3–G3–B3（E 小三和弦外壳）；m.28 同类差异。
  - m.32：A 记 D♯2？本交付/kern/B 为 E2（`8EE`）；m.39：A 多一个 E3。
- **A 的已知转录缺陷**（`来源与许可.md` 亦记）：A、B 都把 m.4 的倚音记成 C6 自然音，而 kern 记 `ccc#` = C♯6 —— 本交付取 **C♯6**（kern，且与 m.9 的 E6→F6、m.8 的 B♮5→C6 构成"下方半音倚音"的一贯写法）。

### 5.2 时值闭合（14/14 小节 = 4.00 拍）

自写 kern 解析器（剩余发声时值模型）逐小节求和：

```
m.1 4.00  m.2 4.00  m.3 4.00  m.4 4.00  m.5 4.00  m.6 4.00  m.7 4.00
m.8 4.00  m.9 4.00  m.10 4.00 m.11 4.00 m.12 4.00 m.13 4.00 m.14 4.00

**独立第二条证据**：LilyPond 编译 **0 error / 0 warning**——4/4 下任何小节若不满或超出 4 拍，`|` 处的 barcheck 必然报警。本交付 14 条 `|` 全静默 ⇒ 每小节恰 4 拍。

### 5.3 交付 .ly 反解析（不依赖 LilyPond 的第三路径）

自写 .ly 扫描器按 `|` 切小节，重算每声部时值合计：14 个小节 × 2 声部全部 4.000；音高（MIDI 号）与 kern 事件表逐小节比对，**0 处无法解释的差异**。

### 5.4 MIDI 实测（第四条路径，LilyPond 自身引擎）

`beethoven-op53-i-mm1-14.mid`：format 1、384 ticks/四分、3 轨（conductor + 2 谱表），**两谱表 program = 0（acoustic grand）**，总长 56.00 拍 = 14×4 ✓。

### 5.5 四处"计数差"= 连音线（非错误）
