## 资料与文章怎样建立关系

学者要打开资料正文并实际阅读，来源卡和助手摘要只帮助发现资料。阅读、理解、分析和写作由学者完成，费时的寻找和转换交给助手。

阅读过程与主要论据保存在本地，来源与许可在 `content/` 外登记。公开正文写音乐，不做逐句出处配对；作者自己的解释需要有根据，但不要求资料作者已经说过同一句结论。

谱例暂缺可以占位。中心知识尚未理解就继续研究，不能把缺研究也包装成“谱例待补”。
