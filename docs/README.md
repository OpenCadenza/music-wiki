## 当前生产边界

正式轮选题不再从贝多芬起步，学者可自由选择音乐主题并决定目录。采用 techniques六维、composers、ensembles、styles、notation，可新建子目录。

初整只在预备轮。正式轮的资料助手自己取得并整理新资料；新资料与预备资料同等可用，也能启发其他学者选题。请求与交付主要通过原生消息，看板展示研究全局。

资料收集助手负责交付谱例的正确性与符合要求，找不到就如实报告；音乐学者无需验谱，可使用占位。

第一批约20篇文章，选题自由。每篇成稿后归档对应研究记录，由主控串行提交local全部非忽略改动；整批结束后再由gpt-6.1-terra / medium集中编辑复读。批后复读不是逐篇归档、提交的前置条件。

正式轮对外层仓库的改动只限content/，不修改根NOTICE、README、脚本或配置；来源与许可先记在local。local资料、研究记录与版本照常维护，重资料继续忽略。当前文档补充不改content，不启动首批写作。
