# 音乐学者公共看板

看板用于了解全局研究，资料请求与交付主要通过 Codex 原生消息传递。现阶段尚未启动音乐学者，故没有在研或归档选题。

## 每个选题一条记录

记录放在 `在研/<学者>-<选题>.md`，由对应音乐学者维护。最少说明：

- 当前问题和研究方向。
- 已读与拟读的资料范围，注明实际阅读进度。
- 拟用作品、案例和需要的资料。
- 拟放的正文目录与文件。
- 当前进度、缺口、与其他选题的关联。

形式从简，内容随研究变化；这不是文章模板，也不是需要主控逐题批准的任务单。开始新选题前阅读其他在研与归档记录，需要时直接联系同行。

## 一篇完成后的收尾

更新记录中的实际资料范围和最终正文位置，将这条记录移入 `归档/`，再通知主控串行提交 local 全部非忽略改动。

原始资料、加工资料与大型产物继续忽略；文档、研究笔记、工具和其他学者已落盘的进行中记录一起形成共享快照。不要并发执行 git add／commit，不为整理提交撤销他人的改动。

local 提交保存研究和协作过程。正式文章属于外层 `content/`，外层提交与发布另行处理。

## 预备轮与正式轮

本轮停在预备轮，等待用户检查资料整理。正式轮选题全领域自由，没有贝多芬优先级。

正式轮没有资料初整代理。资料助手自己整理新增原件入共同阅读库；新资料与预备轮资料同等可用，任何学者都可由它形成选题。

完整规则见[子代理工作流](../子代理工作流.md)。
