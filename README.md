## 计划中的分层

- `origin_resources/`：原始取得的资料，包含教材、研究、作品与作曲家资料、原谱和编码。

- `workbench/`：阅读、研究和草稿。
- `archive/`：旧知识文章及对应登记的完整归档。

这些目标目录尚未创建。具体迁移、忽略规则和完成判据见[纠偏重建计划](docs/纠偏重建计划.md)。

本地音乐文章最终整合到外层 `content/`；公开来源与许可登记在 `NOTICE.md` 等正文之外的位置。local 中的原始资料、历史文章和过程记录不会自动进入正式站点或 OpenViking 知识正文镜像。
